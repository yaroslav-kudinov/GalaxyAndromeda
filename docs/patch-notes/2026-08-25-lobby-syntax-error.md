# Главная страница снова открывается

Дата: 2026-08-25
Ветка: agent/debug-combat-markers-ui

## Суть

После правки полёта значков кораблей главная страница могла не открыться: вместо лобби браузер показывал ошибку загрузки модуля. Причина — опечатка в клиентском коде, а не в правилах. Сейчас экран никнейма и создания комнаты снова загружается.

## Правила

Правила игры не менялись.

## Код

Для разработчиков: в `packages/client/composables/useShipMoveTweens.ts` у функции `clearTweens` после закрывающей скобки остался дубликат тела и лишняя `}`. Из‑за этого esbuild падал с `Unexpected "}"` около строки 239. Превью карты на главной тянет `HexBoard.vue`, а тот импортирует этот модуль — динамический импорт `pages/index.vue` отдавал ошибку.

## API / контракт

Контракт для программ не менялся.

## UI

Главная страница снова показывает экран никнейма и лобби. Если вкладка ещё держит старую ошибку — обновите страницу.

## Тесты

Проверено запросом модуля и отрисовкой главной: заголовок «Galaxy Andromeda» и кнопка «Войти в лобби» на месте.

## Миграции

Миграция сохранений не нужна.
