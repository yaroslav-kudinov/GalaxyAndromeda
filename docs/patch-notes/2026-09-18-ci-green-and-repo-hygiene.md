# Проверка сборки снова зелёная, из репозитория убраны лишние файлы

Дата: 2026-09-18
Ветка: agent/ci-hygiene

## Суть

Автоматическая проверка на GitHub падала с 7 сентября — во всех запусках подряд,
включая ветку `main`. Из-за этого ни одно изменение больше не проверялось: новая
поломка выглядела бы точно так же, как старая, и прошла бы незамеченной.

Причина оказалась не в самой игре. Проверка запускала тесты раньше, чем собирала
пакет правил, а два клиентских теста обращаются к правилам как к собранному
пакету. На чистой копии репозитория собранных правил ещё нет, поэтому эти два
теста падали всегда, а остальные даже не запускались.

Заодно из репозитория убраны файлы, которым там не место: локальная база
разработчика, которая менялась при каждом запуске сервера, и два модуля клиента,
не используемых с тех пор, как постройка переехала в окно маркера действия.

## Правила

Правила игры не менялись.

## Код

- `.github/workflows/ci.yml`: версия Node поднята с 20 до 22 — сервер использует
  встроенный `node:sqlite`, который требует Node 22.5 и выше, как и записано в
  `engines` корневого `package.json`.
- Корневой `package.json`: команда `test` теперь сама собирает `@galaxy/rules`
  перед запуском тестов. Это чинит не только проверку на GitHub, но и первый
  запуск тестов на свежей копии репозитория у любого разработчика.
- `packages/client/package.json`: список тестовых файлов заменён на маску
  `./utils/**/*.test.ts` — раньше каждый новый тест нужно было дописывать в
  команду вручную, и забытый файл молча не запускался. Маска взята в кавычки
  намеренно: без них командная оболочка развернула бы её сама и при появлении
  подкаталога отбросила бы часть тестов.
- `.gitignore`: добавлен каталог `.galaxy-data/`, а лежавшие в нём файлы базы
  убраны из репозитория. В production данные хранятся в `/data` на постоянном
  томе хостинга, а официальные карты сеются из `maps/bundled`, поэтому на
  выкладку это никак не влияет.
- Удалены `packages/client/components/ProductionModal.vue` и
  `packages/client/composables/useProductionShipPick.ts`: на них не осталось ни
  одной ссылки после решения 012 (постройка по маркеру действия, без отдельной
  фазы производства). Живой тип `ShipBuildOrder` перенесён в
  `packages/client/utils/production-build.ts`.

## API / контракт

Контракт для программ не менялся. Устаревшие обёртки `validateProductionBuild` и
`executeProductionBuild` в `@galaxy/rules` оставлены как есть: они входят в
публичный набор пакета, и их удаление стоит проводить отдельно.

## UI

Интерфейс для игрока не менялся.

## Тесты

- Падение проверки воспроизведено локально: после удаления собранных правил
  клиентские тесты дают те же 55 запусков и те же два падения, что и на GitHub.
  После правки та же последовательность на чистой копии проходит целиком.
- Прогнаны все три шага проверки, как на GitHub: тесты (правила 303, клиент 72,
  сервер 4), проверка типов по пяти пакетам и сборка для выкладки.

## Миграции

Миграция сохранений не нужна. У тех, кто уже склонировал репозиторий, при
обновлении пропадёт локальный файл базы `.galaxy-data/galaxy.db` — сервер создаст
его заново при следующем запуске и засеет официальными картами. Партии и карты на
хостинге это не затрагивает: там база лежит отдельно, в `/data`.
