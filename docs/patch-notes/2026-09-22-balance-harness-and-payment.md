# Оплата постройки перестала жечь крупные фишки, появился инструмент замера баланса

Дата: 2026-09-22
Ветка: claude/game-design-economy-balance-bb54c4

## Суть

Игра переплачивала за корабли. Фишка ресурса тратится целиком, сдачи нет, а
автоматический подбор оплаты брал сначала самые крупные — поэтому эсминец за два
кредита мог оплачиваться фишкой номиналом семь, и пять кредитов сгорали впустую.

Теперь автоподбор ищет набор с наименьшим пережогом: за два кредита возьмёт
фишку номиналом два, а крупную оставит нетронутой. Если точного попадания нет,
берётся ближайшая сумма сверху, а при равном пережоге — меньше фишек.

Заодно появился инструмент, который прогоняет сотни партий подряд и считает,
насколько игра разгоняет отрыв лидера. Он понадобится для дальнейшей
перебалансировки: теперь изменения правил можно подтверждать числами, а не
спорами. Первое, что он показал, — правка оплаты сократила потери номинала более
чем вдвое.

Сохранения прошлых версий больше не открываются: правила меняются, и старая
партия по новым правилам неиграбельна. При попытке открыть такой файл игра прямо
об этом говорит. Карты (`.galaxy.json`) открываются по-прежнему.

## Правила

Правила игры не менялись. Изменился только способ, которым игра сама подбирает
фишки для оплаты, когда игрок не выбрал их вручную. Ручной выбор фишек работает
как раньше и по-прежнему главнее автоподбора.

## Код

- `packages/rules/src/production.ts`: `autoAllocateTokens` перешёл с жадного
  отбора по убыванию на подбор с наименьшим пережогом. Задача решается полным
  разбором достижимых сумм — номиналы от одного до девяти, потребность не больше
  двенадцати, поэтому это дешевле любой эвристики.
- `packages/rules/src/save-file.ts`: `GALAXY_SAVE_VERSION` поднят до двойки;
  `parseGalaxySave` отличает сохранение чужой версии от неизвестного формата и
  отвечает понятным текстом.
- `packages/rules/src/observation/ascii-map.ts`: `buildSpatialSummary` строит
  индекс клеток один раз вместо поиска на каждый шаг заливки. На картах в
  полторы-две сотни клеток это заметно: функция вызывается по несколько раз на
  каждый расчёт постройки.
- `packages/client/pages/game/[roomId].vue`: версия сохранения берётся из
  константы правил, а не зашита числом.
- `harness/balance/`: новый пакет `@galaxy/balance`. `rng.ts` — сид прогона,
  `bot.ts` — жадный бот и цикл партии, `metrics.ts` — замеры, `run.ts` —
  разбор аргументов и отчёт. Запуск: `pnpm balance --map duel --games 80`.
  Базовые замеры до правок лежат в `harness/balance/baselines/`.

## Для тех, кто тянет ветку

В репозитории появился новый рабочий пакет `harness/balance`, поэтому после обновления
нужен один `pnpm install` — иначе проверка типов в нём не найдёт компилятор.

## API / контракт

Контракт для программ не менялся. Изменилась только версия формата сохранения:
файлы версии один отклоняются, версия два — текущая.

## UI

Видимых изменений нет. При открытии устаревшего сохранения вместо общего
сообщения о нераспознанном формате показывается объяснение: правила изменились,
старую партию продолжить нельзя, карты открываются по-прежнему.
