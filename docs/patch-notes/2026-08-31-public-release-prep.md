# Подготовка к публичному доступу

Дата: 2026-08-31
Ветка: agent/public-release-prep

## Суть

Игра готовится к открытому доступу: официальный каталог карт на сервере, модерация пользовательских карт, обучение с ботом, админ-панель, юридические документы и усиление безопасности API.

## Правила

Правила игры не менялись. Добавлен режим обучения — один игрок против пассивного тренировочного противника на карте «Дуэль».

## Код

- SQLite-каталог карт и сценариев на сервере (`packages/server/src/db/`).
- Официальные карты: `duel`, `trio-start`, `maltese-cross-4`, `five-point-path` в `maps/bundled/` и `packages/client/public/maps/`.
- Карта «Пятиконечный путь» (`five-point-path`, пять игроков) в том же каталоге.
- Движок сценариев и бот: `packages/rules/src/scenario.ts`, `scenario-runner.ts`, `tutorial-bot.ts`.
- Сценарий `scenarios/tutorial-basics.json`.

## API / контракт

- `GET /api/catalog/maps`, `GET /api/catalog/maps/:id`
- `GET /api/catalog/scenarios`, `GET /api/catalog/scenarios/:id`
- `POST /api/maps/submit` — заявка на модерацию карты
- `POST /api/rooms` с `scenarioId` или `catalogMapId`
- `POST /api/rooms/:id/scenario/next` — ручной шаг обучения
- `GET /api/health` — проверка базы данных
- `/api/admin/*` — управление (Bearer `GALAXY_ADMIN_TOKEN`)

## UI

- Лобби: официальные карты с сервера, без карт редактора в списке создания партии.
- Кнопка «Обучение» на главной.
- Редактор: «На модерацию».
- Страницы `/legal/terms`, `/legal/privacy`, `/faq`, `/admin`.
- Принятие условий при первом входе.
- Панель подсказок обучения в партии.

## Тесты

- `pnpm test`, `pnpm typecheck` — пройти после правок.
- Локально: `pnpm dev`, проверить лобби, обучение, админку.
- `packages/rules/src/tutorial-bot.test.ts`
- GitHub Actions: `pnpm test`, `pnpm typecheck`, `pnpm run build:deploy`

## Миграции

При запуске сервер создаёт SQLite в `GALAXY_DATA_DIR` (локально `.galaxy-data/`, на хостинге `/data`) и добавляет недостающие bundled-карты, даже если каталог уже не пустой. Старые сохранения в браузере не затрагиваются.

## Дополнение (локальный запуск)

На Windows сервер падал при старте из‑за нативного модуля `better-sqlite3`. Клиент показывал «Сервер недоступен — локальная игра», в терминале — отказ соединения на порт 3001.

- База каталога переведена на встроенный `node:sqlite` (Node 22.5+); образ Docker — Node 22.
- Убран дублирующий маршрут `GET /api/health` в `room.ts`.
- Исправлен путь к bundled-картам при первичном заполнении базы.

После `pnpm dev` сервер слушает порт 3001, лобби показывает «Сервер доступен». Файл `.galaxy-data/galaxy.db` совместим.

- Кнопка «Обучение» больше не остаётся неактивной, если сервер поднялся после загрузки страницы: статус проверяется периодически. При первом запуске обучения в меню запрашиваются никнейм и согласие с условиями.
- Онлайн-партии больше не пишут полный сейв в память браузера на каждый ход — исчезает ошибка переполнения при постановке маркера действия.
