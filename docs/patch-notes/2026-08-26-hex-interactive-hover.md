# Наведение подсвечивает клетки, с которыми можно взаимодействовать

Дата: 2026-08-26
Ветка: agent/debug-combat-markers-ui

## Суть

На карте теперь заметнее, куда можно кликнуть. Если навести курсор на клетку, с которой в этот момент можно что-то сделать, она слегка светлеет и обводится. На обычных клетках курсор обычный, на рабочих — указатель.

При выборе клетки назначения после маркера действия над картой — подсказка обычным цветом текста и один слот со значком текущего корабля (как активный в полоске производства: розовая обводка и пульс). Очередь целиком не показывается: только корабль, для которого сейчас выбирают клетку. На карте тот же корабль пульсирует тем же ритмом.

## Правила

Правила игры не менялись.

## Код

Клиент: `HexBoard.vue` — hover-оверлей, класс `interactive`, пульс `ship-active-move-glyph` по `activeShipIds`; `GameBoard.vue` прокидывает ключи; в `pages/game/[roomId].vue` для планирования считаются клетки маркеров, для хода с маркера действия в `activeShipIds` попадает текущий `activeShipId` из `useMarkerMapPick` (и корабль при вопросе о контроле).

## API / контракт

Контракт для программ не менялся.

## UI

- В партии: светлая подсветка при наведении на цели хода, клетки отступления, доступные маркеры действия и производства, а в планировании — на клетки, куда можно поставить или снять маркер. Обводка наведения рисуется поверх границ контролируемых регионов и прочих слоёв карты.
- При выборе назначения с маркера действия на карте пульсирует текущий корабль; в подсказке над картой — обычный цвет текста и один слот со значком (как активный в полоске производства), без всей очереди.
- В редакторе карт: то же наведение на существующих клетках и на пунктирных «призраках» для добавления.
- Курсор-указатель только на рабочих клетках; при перетаскивании карты подсветка наведения снимается.

## Тесты

Вручную: в партии наведите на зелёную цель хода и на клетку с пульсирующим маркером; в планировании — на клетку со своим кораблём; в редакторе — на клетку и на «плюс». При ходе с маркера действия с несколькими кораблями убедитесь, что пульсирует только текущий из баннера.
