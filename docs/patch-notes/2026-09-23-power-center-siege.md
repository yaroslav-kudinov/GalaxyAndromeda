# Центры власти можно осаждать

Дата: 2026-09-23
Ветка: claude/game-design-economy-balance-bb54c4

## Суть

Раньше защищённый центр власти брали только штурмом: вошёл на клетку, выиграл бой — центр
твой. Штурм сильного гарнизона стоил флота, а слабый гарнизон падал за один маркер.

Теперь у нападающего есть второй путь — осада. Флот встаёт на клетку центра рядом с
гарнизоном, и боя нет. Зато в начале каждого хода гарнизон теряет по кораблю, и когда гибнет
последний, центр переходит осаждающему. Осаждающий ничем не платит, кроме того, что его флот
стоит на месте.

Осаждённый не беспомощен. В момент осады его спрашивают, не нападёт ли он сразу. Потом он
может в свой ход выйти на вылазку — дать бой прямо на клетке — или отступить всем гарнизоном,
отдав центр. В бою на своей клетке гарнизон держится крепче: каждый раунд он перебрасывает
промахи, по одному перебросу на каждый свой корабль.

## Правила

- Осадить можно чужой центр власти, где стоят корабли владельца. Пустой центр переходит при
  входе, как раньше.
- При осаде корабли входят на клетку без боя, маркер действия исполнен.
- Осаждённого сразу спрашивают, нападёт ли он. Отказ ничего не стоит.
- В начале каждого хода гарнизон теряет один корабль. Если в гарнизоне корабли разных
  классов, выбирает владелец; если не выбрал — гибнет самый дешёвый. Последний корабль
  гибнет — центр переходит осаждающему.
- Вылазка: маркер действия на своей клетке, кнопка «Атаковать на клетке». Так же осаждающий
  может штурмовать гарнизон, не уходя с клетки.
- Отступить из осады можно только всем гарнизоном, на соседние клетки без вражеских
  кораблей. Центр при этом переходит осаждающему сразу.
- В бою на своей осаждённой клетке осаждённый каждый раунд перебрасывает промахи — по одному
  перебросу на корабль гарнизона.
- Из осаждённой клетки не поддерживают соседние бои, в неё не стреляют обстрелом, осаждённый
  в ней не строит.
- Подкрепление осаждающему входит на клетку без боя. Третий игрок, вошедший в осаждённую
  клетку, бьётся с осаждающим; победив, он сам продолжает осаду.

## UI

В окне подготовки боя на защищённом центре появилась кнопка «Осадить». Осаждённый видит окно
«Ответ на осаду» с кнопками «Готов» и «Не нападать». В окне маркера на клетке с чужими
кораблями есть кнопка «Атаковать на клетке». В карточке клетки центр в осаде помечен.

Выбрать, какой корабль гарнизона потерять, пока нельзя — погибает самый дешёвый. Перебросы
тоже раздаёт игра: сначала по разу на каждый промах.

## Код

- `packages/rules/src/siege.ts`: новый — состояние осад, тик, выбор потерь, отступление.
- `packages/rules/src/combat.ts`: защитник в осаждённой клетке, запрет поддержки и обстрела,
  пул перебросов, подготовка боя на общей клетке.
- `packages/rules/src/movement.ts`: действия осады, вылазки и выбора потерь; осады
  сверяются с доской после каждого действия.
- `packages/rules/src/turn.ts`: тик в начале хода.
- `packages/client`: кнопки осады и вылазки, отметка осады, раздел справки.
- `harness/balance`: бот осаждает, отвечает на осаду, метрики осад.

## API / контракт

Новые действия `establish-siege`, `execute-marker-assault`, `execute-siege-losses`. У
подготовки боя поля `siegeAvailable`, `siegeResponse`, `assaultFrom`. В снимке партии —
`sieges`, `siegeLossesOwedByPlayer`, `siegeTickTurn`; у стороны превью боя — `rerollPool`,
у брошенного кубика — `rerolls`.
