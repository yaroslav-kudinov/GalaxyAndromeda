# Окно итога боя стало короче, а раунд видно на карте

Дата: 2026-08-25
Ветка: agent/debug-combat-markers-ui

## Суть

После бросков в бою на экране было слишком много повторяющихся фраз: кто выиграл, суммы кубиков и что делать дальше говорились по несколько раз. Теперь окно итога короткое: крупные суммы, сами броски и огромная надпись «Победа», «Поражение» или «Ничья». Отдельной строкой написано, кто сейчас решает — выбирает потери, продолжает бой или отступает. На самой карте клетка боя пульсирует, входящие корабли подсвечены, погибшие в раунде на миг остаются призраками.

Решения на сервер по-прежнему уходят сразу. Кнопки «продолжить бой» и «отступить» на баннере не спрятаны за окном итога.

## Правила

Правила игры не менялись. По-прежнему сначала решает атакующий, затем защитник. Пока в этом бою никто не уничтожен, отступление недоступно.

## Код

Для разработчиков: клиент `@galaxy/client`. Окно `BattleModal.vue` — компактный итог и строка статуса из `combatDecisionStatusLine` / `combatRoundOutcome` в `utils/combat-continue-ui.ts` (роль в бою, не ход на карте). Оверлеи карты: `utils/combat-map-fx.ts`, призраки `useCombatDeathGhosts.ts`, пульс и трещины в `HexBoard.vue`. Полёт кораблей по-прежнему из уже применённого снимка; новый `observationRevision` снимает полёт только с исчезнувших глифов. Баннер продолжения и `combat-continue-ui.ts` (очередь, закрытие итога по броскам) не ломались. Сервер и пакет правил не менялись.

## API / контракт

Контракт для программ не менялся.

## UI

В окне итога раунда крупно видно, кто выиграл этот раунд с вашей стороны или, если вы только смотрите, победу атакующего либо защитника. Ниже — броски и суммы. Строка статуса говорит, что происходит сейчас: атакующий выбирает потери, защитник решает продолжить или отступить, стороны ждут подтверждения. На карте клетка боя пульсирует, пока сражение не закончено. Корабли, которые ещё стоят на исходной клетке и должны войти в бой, подсвечены, к клетке боя тянется стрелка. Уничтоженные в раунде корабли коротко остаются призраками с трещиной, затем исчезают — снимок их уже снял. Баннер «продолжить или отступить» поверх карты не перекрывается этими эффектами.

## Тесты

Автоматические проверки в клиенте: очередь продолжения как раньше; новый итог «победа / поражение / ничья» и строки статуса по фазе боя; призраки и стрелки подхода только из снимка. Запуск: `pnpm --filter @galaxy/client test` и `pnpm --filter @galaxy/client typecheck`. Вручную: два клиента, вход в бой, закрыть итог — баннер сразу; на карте пульс клетки и призраки после потерь.
