# Патчноуты переписаны человеческим русским. Правила письма закреплены в инструкциях агента

Дата: 2026-08-25
Ветка: agent/debug-combat-markers-ui

## Суть

Тексты патчноутов приведены к языку игрока: полные предложения, строгий глоссарий, без сокращений и без английских ярлыков в рассказе о партии. Те же правила письма встроены в инструкции агента, чтобы следующие заметки не скатывались в телеграф и аббревиатуры. Механика игры этим заходом не менялась.

## Правила

Правила игры не менялись. В текстах для игрока канон такой: нейтральная клетка, контролируемая клетка, центр власти, кредиты и производство, фишки ресурсов, маркер действия и маркер производства, регион, сдача, колода событий, приоритет уничтожения, обстрел, бой, поддержка. Не «энергоцентр», не сокращения маркеров, не коды карт.

## Код

Для разработчиков: полный глоссарий и запреты — `.cursor/rules/patch-notes.mdc`. Короткие отсылки — `AGENTS.md`, навык `.cursor/skills/galaxy-dev/SKILL.md`, `docs/agent-workflows.md`, этот каталог `docs/patch-notes/README.md`. Страницы `/patch-notes` читают те же файлы; разметка остаётся простой, чтобы клиентский разборщик её понимал.
