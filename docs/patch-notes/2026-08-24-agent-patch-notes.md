# После правок в проекте агент обязан оставить текстовый патчноут

Дата: 2026-08-24
Ветка: agent/debug-combat-markers-ui

## Суть

Чтобы следующие заходы не теряли контекст — что изменилось для игрока, для программ и для старых сохранений — в правила работы агента добавлено обязательство: после правок писать текстовый патчноут в эту папку. Игровые механики в том заходе не менялись. Начатая переработка снабжения, маркеров и сдачи была отменена и в тот день в правила не вошла.
