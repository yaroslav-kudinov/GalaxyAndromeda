# Убраны перевороты фишек, сводка региона на карте и постройка на клетке маркера

Дата: 2026-08-28
Ветка: agent/debug-combat-markers-ui

## Суть

Из колоды событий убраны карты, которые переворачивали все фишки ресурсов лицом вверх или рубашкой вверх. На карте партии можно посмотреть цифры по региону — при долгом наведении или по правому клику на клетку региона. При производстве корабли ставятся только на клетку исполняемого маркера производства, а не на любую клетку региона.

## Правила

- Карты «Активация диверсантов» и «Народное пожертвование» больше не выпадают. В старых сохранениях они превращаются в «Среди звёзд лишь пустота» без эффекта.
- Переворот фишек при оплате производства и при перезарядке региона не менялся.
- Пакетная постройка: все корабли одного маркера — на его клетке (несколько маркеров в регионе исполняются по очереди, каждый на своей клетке).

## Код

- `@galaxy/rules`: `events.ts` — удалены id и эффекты; `regions.ts` — `findRegionAtCell`, `getRegionInfo`; `production.ts` — проверка клетки маркера в `validateShipPlacements` и `regionPlacementCapacity`.
- Клиент: `RegionCellTooltip.vue`, правки `HexBoard.vue`, `GameBoard.vue`, `useProductionShipPick.ts`, `ProductionModal.vue`.

## API / контракт

Контракт для программ не менялся. Экспортированы `RegionInfo`, `findRegionAtCell`, `getRegionInfo` из `@galaxy/rules`.

## UI

- При наведении на клетку региона (около секунды) или по правому клику — подсказка: размер региона, клетки с фишками, активные фишки, кредиты и производство лицом вверх, маркеры производства, центры власти.
- В фазе производства подсвечивается только клетка маркера; подсказки говорят «клетка маркера».

## Тесты

- `events.test.ts`, `index.test.ts` — колода, миграция id, постройка на клетке маркера.
- Вручную: наведение и правый клик на регион, постройка двух эсминцев на одной клетке маркера, отказ при клике на соседнюю клетку региона.

## Миграции

Старые сейвы с картами «Активация диверсантов» и «Народное пожертвование» в колоде или в активном событии хода автоматически заменяются на «Среди звёзд лишь пустота». Миграция карт и сохранений не нужна.
