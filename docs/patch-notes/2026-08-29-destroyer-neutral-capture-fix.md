# Нейтральные клетки: контроль только в конце хода

Дата: 2026-08-29
Ветка: agent/debug-combat-markers-ui

## Суть

Уточнено правило захвата нейтральных клеток: контроль над нейтральной клеткой можно получить **только** в конце хода, после окончания фазы «Действия». Ни мирный заход, ни победа в бою не красят нейтраль сразу — корабли остаются на клетке, а цвет меняется при объявлении контроля.

## Правила

- **Нейтральная клетка:** мирный вход и победа в бою движением не передают контроль сразу.
- **Объявление контроля** (конец хода, после фазы «Действия»): нейтральная клетка с вашими кораблями без вражеских переходит под ваш контроль, если на ней есть эсминец, крейсер, щитоносец, линкор или гиперпространственное орудие.
- **Чужой контроль** без вражеских кораблей: захват сразу при входе или отступлении — как и раньше.

## Код

- `@galaxy/rules`: убран немедленный захват нейтрали из `maybeTransferControl` (`combat.ts`) и `applyControlAfterShipLanding` (`movement.ts`); захват нейтрали только через `applyProductionHexClaims` (`claim.ts`).

## API / контракт

Контракт для программ не менялся.

## UI

На карте нейтральная клетка после боя или мирного захода остаётся без цвета до конца хода; после объявления контроля окрашивается в ваш цвет.
