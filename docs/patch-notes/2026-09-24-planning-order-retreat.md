# Решения начала хода по порядку и честное отступление

Дата: 2026-09-24
Ветка: claude/planning-order-retreat

## Суть

В первый ход нового окна доктрин игра предлагала одновременно выбрать доктрину и занять
клетки, причём лимит захвата был посчитан ещё до выбора. Поэтому «Экспансия» не прибавляла
клетку в том же ходу, хотя должна. Теперь решения начала хода идут строго по порядку, и
каждое следующее считается по итогам предыдущего.

Второе исправление касается боя. Корабли двух игроков могли оказаться на одной клетке без боя.
Так бывало, когда защитник отступал туда, куда тем же маркером летели другие корабли атакующего.

## Правила

Порядок в начале хода, в фазе планирования:

- Потери в осаде: если гарнизону есть из чего выбирать, владелец решает, какой корабль потерять.
- Доктрина — в первый ход каждого окна, все одновременно. Доктрина действует уже в этом ходу.
- Клетки захвата: лимит считается по новой доктрине. Если выбрали «Экспансию», лишняя клетка
  доступна сразу. Пока доктрину не выбрали все, захват ждёт: доктрины вскрываются разом.
- Фишки перезарядки: бюджет считается после захвата, потому что каждый захваченный центр
  власти его уменьшает.
- И только потом игроки расставляют маркеры действия и передают ход.

Пока не принято предыдущее решение, следующее не предлагается. Решения можно принимать вне
своей очереди.

Отступление в бою:

- Защитник не может отступить на клетку, куда тем же маркером летят другие корабли атакующего.
- Остальные корабли маркера долетают после боя. Если на их клетке назначения за время боя
  всё же оказались чужие корабли, второго боя нет: корабль остаётся там, откуда вылетал.

Последний ход партии: после пятнадцатого хода окно доктрин не открывается, а захват последнего
хода засчитывается автоматически. Раньше клетки, которые надо было выбирать, в итог по лимиту
ходов не попадали.

## Код

Для разработчиков: новый модуль `packages/rules/src/planning-order.ts` — `planningStepFor`
определяет текущий шаг игрока, `planningOrderError` отклоняет действие, забегающее вперёд.
В `turn.ts` захват переехал из перехода хода в `beginTurnPlanning`: после тика осады и окна
доктрин. В первый ход окна захват и бюджет считаются при вскрытии доктрин
(`settleAfterDoctrines`). Жадный бот и харнесс закрывают потери в осаде и доктрину вне
очереди раньше всего остального. Отступление: `getCombatRetreatDestinations` исключает клетки
из `continuation.movementPlans`. Дозавершение перелётов в `movement.ts` не сажает корабль
к чужим кораблям.

## API / контракт

- Действия планирования проверяются по порядку: `execute-siege-losses` → `choose-doctrine` →
  вскрытие доктрин → `execute-claim-picks` → `execute-recharge-picks` → `toggle-marker` и
  `advance-phase`. Действие следующего шага до закрытия предыдущего отклоняется с понятным текстом.
- `advance-phase` появляется в списке доступных действий только после всех решений.
- В первый ход окна `claimPicksRemainingByPlayer` пуст, пока доктрины не вскрыты.
- `stop-combat`: защитнику недоступны клетки, куда летят корабли маркера атакующего.

## UI

Карточка «Нужно решить» показывает одно решение за раз и строку шагов: доктрина, клетки
захвата, фишки перезарядки, маркеры действия. Пройденные шаги отмечены зелёным, текущий
выделен. Выбрав доктрину, игрок видит, сколько игроков уже выбрали. Пока решения не приняты,
маркеры не ставятся, а на кнопке передачи хода написано, что сделать сначала. В справке по
правилам описан новый порядок.

## Тесты

- Правила: «Экспансия» в первый ход окна даёт третью клетку; доктрина с платой захватом
  уменьшает лимит; маркеры и передача хода только после всех решений; потери в осаде раньше
  доктрины; вне первого хода окна захват считается сразу; последний ход засчитывает захват.
- Бой: защитник не отступает на клетку, куда летит корабль маркера; корабль маркера не садится
  к чужим кораблям.
- Замер баланса на картах для 2, 4, 5 и 6 игроков — без ошибок, длина партии прежняя.
- Живой сервер: обучение, бои, smoke и партия человека против бота проходят.
- Браузер: ход 4 с тремя игроками — доктрина, затем захват четырёх клеток при «Экспансии»,
  затем перезарядка с пересчитанным бюджетом, затем маркеры.
