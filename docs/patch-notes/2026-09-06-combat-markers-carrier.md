# Исправления по тестовой партии

Дата: 2026-09-06
Ветка: agent/debug-combat-markers-ui

## Суть

Правки после тестовой партии: маркер на центр власти, синхрон бросков для наблюдателей, контрастная подсветка хода, таблица кораблей, обязательная готовность поддержки, возврат авианосца.

## Правила

- Маркер действия можно ставить на **свой центр власти** без корабля на клетке (для постройки).
- Третья сторона с возможностью поддержки **обязана** выбрать сторону или «не поддерживать» — иначе отсчёт боя не стартует.
- **Авианосец** снова в игре: аура своим не-авианосцам в бою — `+1d6` на клетке боя, `+1d4` с соседней; несколько авианосцев не складываются; аура не действует на авианосцы.
- **Щитоносец** усилен: поглощение **6** на клетке / **3** с соседа (было 4/2).
- **Эсминец:** цена уничтожения **3** (было 4) — дуэль эсминец против эсминца на одном кубике снова может закончиться уничтожением при разнице 3.
- **Выбывший игрок** не подтверждает готовность к бою, не выбирает продолжение или отступление и не выбирает потери: бой с его оставшимся флотом идёт без его участия.
- Баланс авианосца (вариант A): ход 1, цена 6 кред. + 5 произв., регион от 12, лимит флота 3, цена уничтожения 5, приоритет уничтожения между щитоносцем и крейсером.

## Код

- `packages/rules/src/markers.ts`, `turn.ts` — размещение маркера на центре власти.
- `packages/rules/src/combat.ts`, `surrender.ts` — выбывший не блокирует prep / continue / уничтожение (`isCombatPrepSideReady`, `syncEliminatedCombatAutomation`).
- Клиент: выбывший не видит кнопки готовности и продолжения боя.
- `packages/rules/data/ships.yaml`, `ships.ts`, `constants.ts`, `types.ts`, `claim.ts`.
- Клиент: подсветка хода (magenta/amber), таблица в справке, UI поддержки, глиф авианосца.
- Сервер: `lastCombatResult` не сбрасывается до старта следующего боя.

## API / контракт

`update-combat-prep` для третьей стороны: выбор стороны с `ready: true` подтверждает готовность.

## UI

- Подсветка достижимых клеток — magenta; целей хода — amber (контраст с зелёным контролем).
- Таблица кораблей: эсминец `1d4`, крейсер `2d6`; добавлен авианосец.
- Выбывший игрок не видит кнопки готовности к бою и решения «продолжить / отступить».

## Тесты

- Маркер на центре власти / отказ на чужом центре.
- Countdown ждёт поддержку третьей стороны.
- Выбывший не нужен для countdown prep против его флота; сдача посреди prep запускает отсчёт.

## Миграции

Старые сейвы без типа `carrier` совместимы. Новые постройки авианосца доступны сразу.
