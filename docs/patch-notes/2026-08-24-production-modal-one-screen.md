# Все покупки фазы производства на одном экране. Полосы прокрутки стали тоньше

Дата: 2026-08-24
Ветка: agent/debug-combat-markers-ui

## Суть

В фазе производства игрок должен сразу видеть все доступные покупки: корабли, дополнительный маркер действия, дополнительный маркер производства и перезарядку фишек. Раньше часть пряталась за шагом «перезарядить или строить», узким списком с прокруткой и кнопкой покупки маркера производства только в шапке партии.

Полосы прокрутки во всём клиенте приведены к тонкому контрастному виду на тёмном фоне.

На тот день дополнительный маркер действия ещё можно было купить в этом окне. Позже покупку маркеров действия убрали отдельным изменением.

## Правила

Правила игры не менялись.

## Код

Для разработчиков: клиент — `ProductionModal.vue` (один экран, сетка классов, плитки покупок), страница партии (покупка маркера производства), `app.vue` (глобальные стили полосы прокрутки: 8 пикселей, тёмный трек, светлый ползунок), текст шага производства в справке.

## API / контракт

Контракт для программ не менялся.

## UI

Окно производства шире: пять карточек кораблей в ряд, на узком экране три плюс две. Ресурсы — одной строкой.

Перезарядка, маркер действия и маркер производства — плитки на том же экране, без отдельного шага и без необходимости прокручивать к опции.

Покупка маркера производства по-прежнему запускает выбор фишек на карте. Кнопка в шапке партии сохранена, если окно ещё не открыто.

Полоса прокрутки тонкая и читаемая на тёмном фоне. Боковая панель, справка и прочие окна используют те же стили. У окна производства вертикальная прокрутка только как запас, если окно совсем низкое; на обычном широком экране все покупки влезают без прокрутки.

## Тесты

Проверка типов клиента. Вручную: фаза производства, щелчок по маркеру — все покупки видны без прокрутки тела окна; купить маркер производства с плитки; узкая боковая панель — полоса прокрутки тонкая и читаемая.
