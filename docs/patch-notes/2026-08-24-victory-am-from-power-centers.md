# Победа считается только по центрам власти. Маркеры действия выдаются за каждый контролируемый центр

Дата: 2026-08-24
Ветка: agent/debug-combat-markers-ui

## Суть

Убрано условие победы «четыре связных региона не меньше чем по семь клеток в каждом». Победить по-прежнему можно двумя способами: контролировать строго больше половины всех центров власти на карте или остаться единственным невыбывшим игроком, в том числе после чужой сдачи.

Маркеры действия больше нельзя купить в фазе производства. Их число равно числу контролируемых вами центров власти: один маркер за каждый центр. Если на старте у вас нет ни одного центра власти, маркеров действия тоже нет — так устроены правила, это не ошибка.

## Правила

Раньше победа засчитывалась при любом из трёх условий: четыре связных региона не меньше чем по семь клеток; большинство центров власти; последний невыбывший игрок. Первое условие снято. Остались строго больше половины всех центров власти на карте (считаются и нейтральные центры без владельца) и последний невыбывший игрок.

Раньше у игрока с начала партии было три маркера действия, а дополнительные можно было докупать в производстве вплоть до восьми (сначала шесть кредитов и шесть производства, затем плюс два и плюс два за каждый следующий). Теперь покупки нет. Сколько центров власти вы контролируете — столько маркеров действия вам доступно.

Потеря центра власти сразу уменьшает этот лимит. Лишние маркеры действия снимаются с карты однозначно. Новый центр, занятый в планировании, сразу даёт ещё один маркер.

Карта события «Авария на производстве» запрещает только покупку дополнительных маркеров производства. На маркеры действия она больше не влияет: их и так нельзя купить.

## Код

Для разработчиков: пакет правил — `victory.ts`, `marker-pools.ts` (лимит и снятие лишних маркеров действия), `production.ts`, `movement.ts`, `claim.ts`, `combat.ts`, `match-start.ts`, `events.ts`, `save-file.ts`, `game.ts`. Клиент: окно производства, страница партии, справка игрока. Решение записано в `docs/decisions/010-victory-am-from-power-centers.md`.

## API / контракт

Для разработчиков: `gameOver.reason` больше не бывает `four_regions`. Поле `actionMarkerLimitByPlayer` считается по числу контролируемых центров власти, а не по купленному запасу (имя поля то же). Действие `execute-production` отклоняет `buyActionMarkers`, если оно больше нуля; пустой список кораблей без такой покупки — ошибка.

## UI

В окне производства больше нет плитки «купить маркер действия». В шапке партии счётчик показывает, сколько маркеров действия сейчас на карте и сколько позволяет контроль центров власти. Справка говорит, что маркеры действия зависят от центров власти, а не «с начала три, максимум восемь».

## Тесты

Автоматические проверки: нет победы по четырём регионам из семи клеток; есть победа по большинству центров власти и по последнему невыбывшему; лимит маркеров по центрам власти; покупка маркеров действия запрещена; потеря центра снимает лишние маркеры; ноль центров даёт ноль маркеров. Запуск пакета правил: `pnpm --filter @galaxy/rules test`.

## Миграции

Старые сохранения с купленным запасом маркеров действия: при загрузке лимит пересчитывается по центрам власти, лишние маркеры на карте снимаются. Бумажную версию для печати не меняли.
