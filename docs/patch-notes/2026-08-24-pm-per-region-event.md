# Несколько маркеров производства в одном регионе разрешены. Ограничение живёт только на карте события

Дата: 2026-08-24
Ветка: agent/debug-combat-markers-ui

## Суть

Постоянное правило «не больше одного маркера производства на регион» снято. Теперь в одном регионе можно ставить несколько маркеров производства: объявление контроля, оплата фишками из региона этого маркера и покупка дополнительных маркеров больше не упираются в искусственный потолок.

Ограничение «один маркер производства на регион» действует только пока на столе лежит нужная карта события. Отдельной новой карты в колоду не добавляли: прежняя «Сверхурочные» касалась **фишек** производства в регионе. Её не выкидывали. Тот же лист переименовали в «Нормирование производства» и перевернули эффект: теперь карта ограничивает именно маркеры производства.

Когда вытягивается и сразу применяется новая карта хода, на экране появляется окно объявления: номер хода, название и краткий эффект. Это не кнопка «Применить» — карта уже действует, нужно только прочитать.

## Правила

Раньше в планировании нельзя было поставить второй маркер производства в тот же связный регион владельца; сохранение с двумя такими маркерами считалось неверным. Карта «Сверхурочные» разрешала любое число **фишек** производства в одном регионе, но не больше числа клеток.

Стало так.

По умолчанию в одном регионе можно несколько маркеров производства. По-прежнему не больше одного маркера на клетку. Сколько маркеров вам доступно — столько вы купили в запас.

Пока действует «Нормирование производства», у вас не больше одного своего маркера производства на регион. Регион — связная группа ваших контролируемых клеток. Чужой маркер в «том же» регионе оказаться не может: это уже чужой контроль.

Если карта вытянулась, а на карте уже стоят два или больше маркера в одном регионе, лишние **возвращаются в неиспользованный запас** без траты действия фазы. В регионе остаётся один маркер. Остальные правила региона не менялись: минимум клеток для класса корабля, оплата фишками из региона маркера, объявление контроля. Условие победы «четыре региона по семь клеток» в тот день ещё существовало и этим патчем не трогалось.

## Код

Для разработчиков: пакет правил — `events.ts` (текст карты, флаг `oneProductionMarkerPerRegion`, снятие лишних маркеров; на карте остаётся маркер с меньшим идентификатором), `markers.ts` (активно ли нормирование), `production.ts` (убрана проверка сверхурочных по фишкам), `save-file.ts` (сохранение больше не отвергает несколько маркеров на регион). Клиент: `TurnEventAnnounceModal.vue`, страница партии, окно производства, справка. Поле снимка `overtimeRegionByPlayer` оставлено, чтобы старые файлы открывались, но больше не записывается.

## API / контракт

Для разработчиков: `types.ts` не менялся. Наблюдение по-прежнему отдаёт `turnEvent`. Текст карты — в `EVENT_CARDS` под прежним кодом `mandatory-overtime`. Постановка маркера идёт через `toggle-marker` / `addProductionMarker`.

## UI

В планировании можно выбрать вторую клетку того же региона, пока нет «Нормирования производства». Если карта активна, игра подскажет и откажет.

В окне производства оплата по-прежнему берётся из региона этого маркера. При активном нормировании видна явная строка: не больше одного маркера производства на регион.

В справке и таблице событий название «Нормирование производства» вместо «Сверхурочные».

Окно нового хода: номер хода, название карты и краткий эффект. Закрывается кнопкой «Понятно» или щелчком по фону. Браузер запоминает, что вы уже видели объявление этой комнаты на этом ходе с этой картой. Если вы вошли в комнату посреди хода, окно не всплывает повторно. Карточка события на боковой панели без изменений.

## Тесты

Автоматические проверки пакета правил: два маркера производства в одном регионе без события; событие блокирует второй маркер; лишние снимаются в запас, фаза не тратится; постройка с двух маркеров в регионе по-прежнему платит фишками из региона маркера. Вручную: смена хода показывает объявление один раз; обновление страницы посреди хода не повторяет его; карточка на боковой панели на месте. Запуск: `pnpm --filter @galaxy/rules test`.

## Миграции

Старые сохранения с двумя маркерами производства в одном регионе теперь допустимы. Если в файле уже лежит «Нормирование производства» и на карте несколько маркеров в регионе, лишние снимутся только при следующем применении карты (в обычном ходе применение уже прошло).
