# Партия длится не больше пятнадцати ходов, а порог победы теперь задаёт карта

Дата: 2026-09-22
Ветка: claude/game-design-economy-balance-bb54c4

## Суть

Партия могла не закончиться вообще. На карте «Мальтийский крест» четыре игрока в
большинстве случаев не добирали нужное число центров власти и за пятьдесят ходов —
игра просто продолжалась.

Теперь у партии есть срок: пятнадцать ходов. Если к его концу никто не набрал
нужного числа центров власти, победитель определяется по порядку: у кого больше
центров власти, затем у кого больше клеток, затем у кого больше номинала фишек
лицом вверх, и в самом крайнем случае — жребием партии. Победитель есть всегда.
Обучение сроком не ограничено: урок важнее темпа.

Заодно изменилось само условие победы. Раньше побеждал тот, кто взял больше
половины всех центров власти на карте, — и подвинуть темп партии, не перекраивая
карту, было нельзя. Теперь нужное число задаёт сама карта. Опубликованные карты
пока играют по-старому: своё число им выставят, когда их переложат под новую
экономику.

И третье: маркеров действия теперь всегда шесть. Раньше их было «три плюс число
ваших центров власти», из-за чего центр власти давал сразу две выгоды — и приближал
победу, и добавлял действие. В партиях у игроков накапливалось по девять-одиннадцать
маркеров. Теперь число действий за ход одинаково у всех и не меняется.

## Правила

- Партия длится не больше пятнадцати ходов. По их истечении победитель определяется
  цепочкой: центры власти → клетки → номинал фишек лицом вверх → жребий партии.
- Для победы нужно захватить столько центров власти, сколько указано на карте.
  Если карта числа не указывает, действует прежнее правило «больше половины».
- Маркеров действия за ход — шесть у каждого игрока, всю партию.

## Код

- `packages/rules/src/victory.ts`: `victoryThresholdFor`, `resolveTurnLimitWinner`,
  `provisionalWinnerForSnapshot`, `isTurnLimitReached`; `VictoryReason` пополнен
  значением `turn_limit`.
- `packages/rules/src/types.ts`: `MapDefinition.victoryPowerCenters`, поля порога и
  лимита на `GameState`.
- `packages/rules/src/save-file.ts`: `GameSnapshot.victoryPowerCenters`, `turnLimit`,
  `matchSeed`; поля протащены через нормализацию снимка и обмен с наблюдением.
- `packages/rules/src/match-start.ts`: `DEFAULT_TURN_LIMIT`, параметр `turnLimit`
  у старта матча (`null` — без лимита, для обучения), бросок сида партии.
- `packages/rules/src/marker-pools.ts`: `ACTION_MARKER_LIMIT` вместо формулы от
  числа центров власти.
- `packages/server/src/room.ts`: обучающие комнаты стартуют без лимита ходов.
- `harness/balance/`: флаги `--victory` и `--turnLimit` для подбора чисел замерами.

## API / контракт

`GameObservation` пополнен полями `victoryPowerCenters`, `turnLimit` и `matchSeed`.
Формат карты пополнен необязательным полем `victoryPowerCenters`. Значение
`turn_limit` добавлено к причинам завершения партии.

## UI

У завершения партии по сроку появилась подпись «Лимит ходов» — раньше на её месте
показался бы служебный код.
