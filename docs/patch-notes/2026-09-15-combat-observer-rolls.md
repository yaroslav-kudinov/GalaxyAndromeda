# Наблюдатели боя снова видят броски кубиков

Дата: 2026-09-15
Ветка: main

## Суть

Игроки жаловались, что со стороны бой смотреть невозможно. Тот, кто не участвует в сражении
сам — не нападает, не защищается и не поддерживает соседними кораблями, — вместо броска кубиков
получал пустое окно и не понимал, чем закончился раунд. Помогала только перезагрузка страницы, а
она же и стирала итог: после неё окно просто не открывалось.

Причина была в самом окне боя. У участников оно открывается заранее, ещё на подготовке, и к
моменту броска уже готово к показу. У постороннего наблюдателя оно создаётся позже — сразу с
готовым итогом раунда, — и в этот момент показ бросков запускался раньше, чем окно успевало
подготовить своё внутреннее состояние. Окно падало с ошибкой и не отрисовывалось.

Теперь наблюдатель видит то же, что и участники: кубики открываются по одному, затем сумма
сторон, победитель раунда и потери.

## Правила

Правила игры не менялись. Ни броски, ни порядок боя, ни выбор потерь не затронуты — исправлен
только показ уже случившегося боя тем, кто в нём не участвует.

## Код

- `@galaxy/client`, `components/BattleModal.vue`: состояние показа бросков (`revealTimer`,
  `destructionReviewReady`, `destructionReviewTimer`) поднято выше наблюдателя с
  `immediate: true`, который запускает анимацию прямо во время подготовки компонента. Раньше эти
  объявления шли ниже по файлу и попадали во временную мёртвую зону: `startRevealAnimation`
  падал с `ReferenceError`, и вместе с ним не отрисовывалось всё окно боя.

## API / контракт

Контракт для программ не менялся. Сервер и раньше отдавал итог боя всем игрокам комнаты —
проблема была целиком на стороне интерфейса.

## UI

- Постороннему наблюдателю окно боя открывается с прокруткой кубиков, суммами сторон, именем
  победителя раунда и списком потерь — как у участников.
- Перезагружать страницу, чтобы «починить» окно, больше не нужно.

## Тесты

- `@galaxy/client`: `utils/battle-modal-script-order.test.ts` — проверяет, что состояние показа
  бросков объявлено выше немедленного наблюдателя; при возврате объявлений вниз тест падает.
- Вручную: партия на троих, бой первого игрока со вторым, третий смотрит со стороны. Проверены
  оба исхода — бой, закончившийся за один раунд, и бой с выбором потерь победителем.

## Миграции

Миграция сохранений не нужна.
