# Тексты игры переезжают в один словарь, начали с девяти панелей

Дата: 2026-09-18
Ветка: agent/ui-strings

## Суть

Подписи, кнопки и пояснения были разбросаны прямо по файлам интерфейса — около
семисот кусков текста в трёх десятках мест. Из-за этого формулировки жили сами
по себе: где-то «правая панель», где-то «боковая», где-то канцелярит вроде
«не зафиксированы в журнале». Вычитать всё разом было негде.

Теперь тексты переезжают в один файл-словарь. Переезд идёт частями, и эта часть
переносит девять панелей. Заодно у переносимых надписей поправлены формулировки:
они приведены к общему словарю игры и записаны человеческим языком.

Чтобы разброд не начался заново, добавлена проверка: новый файл интерфейса с
зашитым текстом не пройдёт сборку. Для ещё не перенесённых файлов есть список
исключений, и он умеет только сокращаться — как только текст из файла вычищен,
проверка требует убрать его из списка.

## Правила

Правила игры не менялись.

## Код

- `packages/client/utils/ui-text-scan.ts`: поиск русского текста в разметке
  компонента. Комментарии и стили не считаются нарушением — пояснения на русском
  в коде это хорошо.
- `packages/client/utils/ui-strings-guard.test.ts`: проверка-храповик. Роняет
  сборку, если текст зашит в файл вне списка исключений, и если запись списка
  устарела.
- `packages/client/i18n/untranslated-baseline.ts`: список файлов, где текст ещё
  зашит. Было 33, осталось 24.
- `packages/client/i18n/ui-strings.ts`: новые разделы словаря — `patchToast`,
  `cell`, `rulesHelp`, `lobbyPlayers`, `coach`, `turnEvents`, `turnAnnounce`,
  `productionOrder`, `slots`.
- Переведены на словарь: `PatchUpdateToast`, `HexCellTooltip`, `RulesHelpModal`,
  `LobbyPlayerList`, `ScenarioCoachPanel`, `TurnEventsPanel`,
  `TurnEventAnnounceModal`, `ProductionOrderStrip`, `LobbySlotPicker`.

## API / контракт

Контракт для программ не менялся.

## UI

Изменились только формулировки перенесённых надписей:

- Объявление начала хода раньше говорило «Карта уже применена автоматически. Это
  объявление, не подтверждение». Было неясно, речь о карте события или об игровой
  карте, и половина фразы объясняла, чем является само окно. Стало: «Карта
  события уже вступила в силу — подтверждать ничего не нужно».
- Пояснение про счётчик перезарядки стало прямым: «Когда счётчик дойдёт до нуля,
  перевёрнутые фишки ресурсов снова станут доступны».
- В справке по правилам вместо «Краткая однозначная выжимка на русском.
  Подсказка текущего хода — в правой панели» теперь «Короткий разбор правил.
  Подсказка для текущего хода — в боковой панели» — и панель названа так же, как
  в остальной игре.
- Пустой список прошлых ходов раньше сообщал, что события «не зафиксированы в
  журнале». Стало: «Прошлых ходов ещё не было — здесь появится их история».
- Подсказка к кораблю в заявке на постройку была телеграфной: «Щелчок — убрать
  этот и следующие». Стало: «Щёлкните, чтобы убрать этот корабль и все следующие
  за ним».
- В списке игроков комнаты статус «на странице игры» заменён на «на странице
  партии», а «ожидаем» — на «ждём игрока».

## Тесты

- `utils/ui-text-scan.test.ts` — десять проверок поиска: текст в разметке и в
  строках кода находится вместе с номером строки, комментарии и стили не
  считаются, обращение к словарю нарушением не является, нумерация строк не
  сбивается после вырезанных блоков.
- `utils/ui-strings-guard.test.ts` — сама проверка-храповик: файл вне списка с
  зашитым текстом роняет её, устаревшая запись в списке тоже.
- Проверено вручную: обучение (панель подсказок, объявление начала партии,
  события хода), справка по правилам, короткое уведомление о патчноуте.
