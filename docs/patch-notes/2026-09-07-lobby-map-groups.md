# В выборе карты лобби разделены официальные и локальные

Дата: 2026-09-07
Ветка: agent/public-release-prep

## Суть

В лобби список карт больше не смешан в одну кучу. Сначала идут предустановленные карты с сервера, ниже — карты, сохранённые в этом браузере (редактор, импорт файла). Если локальная копия совпадает по имени с официальной, обе остаются в списке отдельно.

## Правила

Правила игры не менялись.

## Код

- Страница `packages/client/pages/index.vue`: группы в `select` (`optgroup`), ключ выбора `official:…` / `local:…`, локальные карты из `galaxy-lobby-saves` и `galaxy-maps`.

## API / контракт

Контракт для программ не менялся.

## UI

На экране «Играть» в поле «Карта» две группы: «Предустановленные на сервере» и «Сохранённые локально». Импорт файла попадает во вторую группу.

## Тесты

Открыть «Играть», раскрыть список карт: официальные сверху. Если в браузере есть карты редактора или импорт — они во второй группе. Выбрать официальную и локальную по очереди, проверить превью.

## Миграции

Миграция сохранений не нужна.
