# Крупное обновление правил, постройка в действиях и политика деплоя

Дата: 2026-08-29
Ветка: agent/debug-combat-markers-ui

## Суть

Упрощён цикл хода: остаются три фазы — события, планирование, действия. Маркеры производства и отдельная фаза производства убраны; корабли строятся по маркеру действия в фазе «Действия». Эсминцы захватывают нейтральные клетки при объявлении контроля, но слабее в бою, чем крейсеры. Перевёрнутые фишки ресурсов снова открываются автоматически через случайный интервал один, два или три полных хода; в шапке партии видно, когда будет следующая перезарядка. Стартовый запас маркеров действия при одном центре власти — четыре. В harness зафиксировано: production-сборку на хостинг выкладываем только по явной централизованной команде, не при каждом push.

## Правила

- **Фазы:** события → планирование → действия → (новый ход) события. Фазы «Производство» больше нет.
- **Постройка:** по маркеру действия в фазе «Действия»; новые корабли появляются на клетке маркера; оплата фишками региона как раньше при производстве.
- **Маркеры производства:** механика отключена; покупка и расстановка не доступны.
- **События:** из колоды убраны «Авария на производстве» и «Нормирование производства» — они касались только маркеров производства. Осталось 12 типов карт.
- **Объявление контроля:** после фазы «Действия», перед картой события нового хода. Эсминцы участвуют в захвате нейтральных клеток; после победы в бою на нейтрали эсминец забирает контроль сразу.
- **Бой:** эсминец — один кубик с четырьмя гранями; крейсер в прямом бою — два кубика с шестью гранями (раньше у крейсера было два кубика с четырьмя гранями).
- **Маркеры действия:** лимит = три плюс число ваших центров власти (при одном центре — четыре с самого начала).
- **Перезарядка фишек:** автоматически в конце хода, когда истечёт случайный интервал один, два или три полных хода; после каждой перезарядки интервал бросается заново и показывается в шапке партии.

## API / контракт

- В снимке партии: `resourceRechargeTurnsRemaining` (1 | 2 | 3 — полных ходов до следующей перезарядки).
- Старые сейвы с фазой «production» переводятся в «actions»; маркеры производства снимаются.
- Из колоды событий убраны «Авария на производстве» и «Нормирование производства»; старые id в сейвах и колоде мигрируют в «Среди звёзд лишь пустота».
- Действие `execute-production` по-прежнему строит корабли, но только в фазе «Действия» и по id маркера действия.

## UI

- Планирование: только маркеры действия (без подшага «маркеры производства»).
- Постройка: вкладка «Постройка» в окне маркера действия (перемещение, обстрел, постройка).
- В шапке партии — строка «Перезарядка фишек через N ходов» (или «в конце этого хода»).
- С карты и из боковой панели убраны розовые обводки и значки маркеров производства, блок «Производство» в списке маркеров, кнопки покупки и снятия, предупреждения о нерасставленных маркерах производства.
- Уведомление о смене фазы: старый снимок с фазой «production» показывается как «Действия».
- Подсказки в справке обновлены под новый цикл и лимит маркеров.
- В таблице событий в «Правилах» больше нет карт про маркеры производства.

## Миграции

- При загрузке старых сохранений: фаза «production» → «actions», очистка маркеров производства; устаревшее поле `resourceRechargeInterval` переносится в `resourceRechargeTurnsRemaining`.
