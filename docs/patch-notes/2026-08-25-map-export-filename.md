# При сохранении карты на диск файл называется по названию карты

Дата: 2026-08-25
Ветка: agent/debug-combat-markers-ui

## Суть

Когда вы скачиваете карту или партию на компьютер, браузер подставляет в имя файла **название** карты — то, которое видно в редакторе и в шапке партии. Раньше в редакторе файл всегда назывался по служебному коду карты, и на диске получалось что-то вроде внутреннего ярлыка вместо человекочитаемого имени. Внутри файла служебный код по-прежнему лежит на своём месте: меняется только имя скачанного файла.

## Правила

Правила игры не менялись.

## Код

Для разработчиков: общая функция `galaxySaveDownloadFileName` в `packages/rules/src/save-file.ts`. Клиент: экспорт в `packages/client/pages/editor/index.vue` (`exportJson`) и «↓ Экспорт» в `packages/client/pages/game/[roomId].vue`. Поле `map.id` в JSON не трогали.

## API / контракт

Контракт для программ не менялся. Формат сохранения тот же; меняется только имя файла при скачивании в браузере.

## UI

В редакторе карт кнопка «Экспорт» сохраняет файл с названием карты (например «Черновик» или «Новая карта»), с расширением как у обычного сохранения партии. На странице партии поле «Имя» по-прежнему можно править вручную; по умолчанию там тоже название карты. Символы, которые нельзя использовать в имени файла, заменяются на подчёркивание. Если название пустое, файл называется по служебному коду карты.

## Тесты

Покрыто: название на русском без транслитерации, замена запрещённых символов, пустое название → служебный код, отрезание уже дописанного расширения. Вручную: в редакторе задать название, нажать «Экспорт», убедиться, что скачанный файл назван по названию, а служебный код внутри файла прежний.

## Миграции

Миграция сохранений не нужна.
