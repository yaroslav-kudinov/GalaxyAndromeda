# На телефоне кнопка завершения хода стоит между чатом и панелью «Игра»

Дата: 2026-09-10
Ветка: agent/mobile-phase-fab-row

## Суть

На узком экране кнопка продолжения или завершения фазы раньше занимала отдельную полосу в самом низу и часто уезжала под край экрана или зону жестов телефона — её было почти невозможно нажать. Теперь она в одном нижнем ряду с кнопками «Чат» и «Игра», по центру между ними, с отступом от нижнего края и индикатора «домой».

## Правила

Правила игры не менялись.

## Код

- Клиент: `packages/client/pages/game/[roomId].vue` — мобильный `mobile-phase-dock` стал компактной кнопкой по центру; FAB «Игра» справа, чат слева; общий `--mobile-fab-bottom` с `safe-area-inset-bottom` вместо второго «этажа» `--mobile-dock-offset`.

## API / контракт

Контракт для программ не менялся.

## UI

- На телефоне в свой ход нижний ряд: слева «Чат», по центру кнопка смены фазы (завершить планирование, ход и тому подобное), справа «Игра».
- Кнопка фазы не уезжает под край экрана; отступ учитывает безопасную зону снизу.
- На широком экране шапка и кнопка фазы в центре шапки без изменений.

## Тесты

- Проверка типов клиента при необходимости.
- Вручную при ширине около 390 пикселей в свой ход: видны три кнопки в одном ряду, фаза нажимается пальцем, нет перекрытия индикатором «домой».

## Миграции

Миграция сохранений не нужна.
