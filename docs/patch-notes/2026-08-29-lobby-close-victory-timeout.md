# Закрытие комнаты и автозакрытие после победы

Дата: 2026-08-29
Ветка: agent/debug-combat-markers-ui

## Суть

Создатель комнаты подготовки может закрыть её до начала игры — комната исчезает с сервера, остальные игроки больше не смогут войти по ссылке. После победы одного из игроков комната автоматически закрывается через тридцать секунд: на экране показывается обратный отсчёт, затем все возвращаются на главную страницу.

## Правила

Правила игры не менялись.

## Код

Сервер: `closeRoom`, таймер `VICTORY_ROOM_CLOSE_MS` в `packages/server/src/room.ts`, маршрут `POST /rooms/:id/close`. Клиент: `closeRoom` в `useGameApi.ts`, кнопка и таймер в `pages/game/[roomId].vue`.

## API / контракт

Новый запрос: `POST /rooms/:id/close` с телом `{ playerId }` — только создатель, только пока комната в статусе подготовки. После победы комната удаляется сервером через тридцать секунд; запросы к ней возвращают ошибку «комната не найдена».

## UI

В комнате подготовки у создателя появилась кнопка «Закрыть комнату». На экране победы — строка с обратным отсчётом до возврата на главную.

## Тесты

Вручную: создать комнату, закрыть как создатель — ссылка должна перестать открываться. Довести партию до победы — через тридцать секунд редирект на главную, комната пропадает из списка лобби.

## Миграции

Миграция сохранений не нужна.
