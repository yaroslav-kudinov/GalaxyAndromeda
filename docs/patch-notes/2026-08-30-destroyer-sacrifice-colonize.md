# Захват нейтрали эсминцем только жертвой

Дата: 2026-08-30
Ветка: agent/debug-combat-markers-ui

## Суть

Эсминец больше не захватывает нейтральные клетки как остальные колонизаторы в конце хода. Единственный способ — **жертва**: в окне маркера действия на клетке с эсминцем откройте вкладку «Жертва эсминца», выберите корабль и подтвердите. Эсминец уничтожается, клетка сразу под вашим контролем. Один эсминец — одна клетка — один маркер действия. Это отдельное действие, не связанное с перемещением.

## Правила

- **Крейсер, щитоносец, линкор, гиперпространственное орудие:** нейтральную клетку занимают в конце хода после фазы «Действия», если на ней остались ваши корабли без врагов.
- **Эсминец:** мирное стояние на нейтрали и победа в бою контроль не дают. Захват — только жертва через окно маркера действия на клетке, где стоит эсминец.
- **Чужой контроль** без вражеских кораблей: захват сразу при входе — без изменений.

## Код

- `@galaxy/rules`: `destroyer-sacrifice.ts` (`getSacrificableDestroyersAtMarker`, `executeDestroyerSacrifice`), `claim.ts`, `movement.ts` (действие `execute-destroyer-sacrifice`; `declareControl` в движении отключён).
- Клиент: вкладка «Жертва эсминца» в окне маркера действия (`MarkerActionModal.vue`).

## API / контракт

- Действие `execute-destroyer-sacrifice`: параметры `from` (координата маркера) и `shipId` (идентификатор эсминца на этой клетке).
- Поле `declareControl` в плане движения маркера больше не используется для захвата.

## UI

При клике на маркер действия с эсминцем на нейтральной клетке появляется вкладка «Жертва эсминца»: выбор корабля и кнопка «Жертвовать эсминцем». При перемещении эсминца захват не предлагается.
