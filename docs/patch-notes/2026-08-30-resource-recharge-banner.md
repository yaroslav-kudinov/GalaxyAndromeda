# Крупный счётчик перезарядки ресурсов

Дата: 2026-08-30
Ветка: agent/debug-combat-markers-ui

## Суть

Игрокам нужно было явно видеть, через сколько полных ходов наступит автоматическая перезарядка перевёрнутых фишек ресурсов. Счётчик вынесен крупным текстом в блок событий и в модальные объявления.

## Правила

Правила игры не менялись.

## Код

- `@galaxy/rules`: `formatResourceRechargeBannerText` в `resource-recharge.ts`.
- Клиент: `ResourceRechargeBanner.vue`, `useResourceRechargeIntroAnnounce.ts`, доработка `TurnEventAnnounceModal.vue` и `TurnEventsPanel.vue`.

## API / контракт

Контракт для программ не менялся.

## UI

- В боковой панели в блоке «События хода» всегда видна строка вида **«До перезарядки ресурсов — N ходов»** (крупный жёлтый баннер).
- В начале партии (ход 1) — отдельное объявление только со счётчиком, без карты события.
- При объявлении новой карты события — тот же крупный счётчик над текстом события.

## Тесты

- `pnpm --filter @galaxy/rules test` — формат баннера.
- `pnpm typecheck`.

## Миграции

Миграция сохранений не нужна.
