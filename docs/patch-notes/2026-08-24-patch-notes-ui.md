# История изменений доступна в клиенте. О свежем патчноуте напоминает короткое уведомление

Дата: 2026-08-24
Ветка: agent/debug-combat-markers-ui

## Суть

Клиент не просит согласие на сохранение данных в браузере и не показывает баннер об этом. Игроки видят ненавязчивое уведомление о свежем патчноуте и могут открыть историю на странице «Патчноуты» — там полные тексты из этой папки.

## Правила

Правила игры не менялись.

## Код

Для разработчиков: клиент собирает файлы `docs/patch-notes/*.md`, показывает уведомление `PatchUpdateToast.vue` и страницы `pages/patch-notes/`.

## API / контракт

Контракт для программ не менялся.

## UI

Справа снизу короткое уведомление: заголовок, краткая суть, кнопки «Читать» и «Понятно». На страницах патчноутов уведомление скрыто.

В шапке и на главном экране есть ссылка «Патчноуты».

## Тесты

Вручную: главный экран — уведомление — список — карточка патчноута — «Понятно» скрывает уведомление.

## Миграции

Миграция сохранений не нужна.
