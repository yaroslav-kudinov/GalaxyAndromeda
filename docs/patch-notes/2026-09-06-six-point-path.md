# В каталог добавлена карта «Шестиконечный путь»

Дата: 2026-09-07
Ветка: agent/public-release-prep

## Суть

В официальный каталог поставлена карта «Шестиконечный путь» на шестерых — экспорт из редактора. У каждого дома два центра власти, фишка кредитов 7, фишка производства 5, четыре эсминца и два крейсера. Расклад фишек и прорехи в центре — как в этом экспорте.

## Правила

Правила игры не менялись.

## Код

- Исходник `maps/bundled/six-point-path.source.galaxy.json`, игровые копии `six-point-path.json` в `maps/bundled/` и `packages/client/public/maps/`.
- Сид `seedBundledMaps` в `packages/server/src/db/index.ts` обновляет официальные карты из файлов репозитория (строки с источником `bundled`), пользовательские заявки не затирает.
- Скрипт `harness/scripts/generate-six-point-path.ts` — черновик, канон не он.

## API / контракт

После сида `GET /api/catalog/maps` отдаёт карту с идентификатором `six-point-path`.

## UI

В списке официальных карт лобби появляется «Шестиконечный путь» (шесть игроков).

## Тесты

Импорт: шесть игроков, 223 клетки; у каждого игрока четыре эсминца и два крейсера. После выкладки — перезапустить сервер и создать комнату из этой карты.

## Миграции

Существующая база не сбрасывается. При старте сервера официальные bundled-карты перечитываются из файлов каталога.
