# В редакторе карт починили зеркало симметрии и автоотдаление камеры

Дата: 2026-08-25
Ветка: agent/debug-combat-markers-ui

## Суть

На вкладке «Симметрия» в редакторе карт можно выбрать зеркало для двух игроков, ось через центры гексов и горизонталь. Кнопки уже выглядели выбранными, но кисть отражала не так: режимы «через центры» и «через границы» давали одно и то же отражение, а подпись «горизонталь» не соответствовала картинке на поле. Теперь шесть направлений зеркала различаются, подписи зависят от ориентации гексов, и желаемая комбинация действительно зеркалит.

Отдельно: при добавлении и удалении клеток карта сама уменьшалась и уезжала, даже если зум уже выставили руками. Кадр подстраивался под всю карту. Теперь по умолчанию этого нет; если нужно, чтобы камера следила за картой, это включается кнопкой в управлении камерой.

## Правила

Правила партии не менялись. Меняется только помощник рисования и камера в редакторе карт.

## Код

Для разработчиков: в `packages/rules/src/hex-symmetry.ts` отражение больше не крутит одну ось на шестьдесят градусов (так получались только три оси из шести). Семейство «через центры» — отрицание кубической оси, семейство «через границы» — обмен кубических координат. Подписи: `getSymmetryAxisLabels`. Клиент: вкладка симметрии в `packages/client/pages/editor/index.vue`, ориентация поля пробрасывается через `GameBoard`.

Камера: `autoFitFromStorageValue` в `packages/client/utils/hex-layout.ts` — без ключа в браузере подгонка выключена; кнопка в `HexBoard.vue`. Партия и превью в лобби по-прежнему передают подгонку включённой, чтобы карта не сжималась в угол из‑за настройки редактора.

## API / контракт

Контракт для программ не менялся. Сохранения карт не хранят настройки симметрии и камеры редактора: они по-прежнему только в браузере.

## UI

В редакторе карт, вкладка «Симметрия»: включите режим, выберите двух игроков, «Ось через центры гексов».

Горизонтальное зеркало через центры клеток возможно, только когда поле показано **углом вверх** (кнопка ориентации на карте). Если гексы стоят гранью вверх, такой горизонтали нет — панель пишет, почему, и предлагает «Показать карту углом вверх». После этого первая кнопка оси называется «горизонталь», кисть сразу рисует пару клеток сверху и снизу, слоты игроков меняются местами.

Если карта гранью вверх и нужна именно горизонталь, выберите «Ось через границы» — там горизонталь есть, но линия проходит между клетками, а не через ряд центров.

Для четырёх игроков те же оси видны, потому что этот режим тоже отражает. Для трёх и шести игроков по-прежнему только поворот, оси не показываются. Кнопка «Досоздать недостающие клетки» не обязательна для кисти: новые клетки зеркалятся сразу; кнопка добивает копии уже нарисованных клеток.

Внизу слева, рядом с «Грань» и «Угол», кнопка **«Подгонять»**. По умолчанию выключена: рисуете или стираете клетки — зум и сдвиг не сбрасываются. Включите (кнопка подсветится), если хотите, чтобы кадр сам охватывал всю карту, когда она растёт. Плюс, минус, процент и кружок сброса вида работают как раньше. В партии этой кнопки нет: там карта всегда в кадре целиком.

## Тесты

Покрыто: шесть разных отражений одной клетки, «через центры» и «через границы» не совпадают, горизонталь через центры только при ориентации углом вверх, кисть для двух игроков меняет слоты местами, четыре игрока по-прежнему дают четыре копии. Для камеры: без сохранённого ключа подгонка выключена, включается только явной единицей. Вручную: открыть редактор, симметрия, два игрока, через центры, переключить поле на «углом вверх», выбрать «горизонталь», дорисовать клетку и убедиться, что появляется отражение сверху или снизу и карта не отдаляется; включить «Подгонять» — при следующей клетке кадр охватывает всю карту.

## Миграции

Миграция сохранений не нужна. Старые настройки симметрии в браузере остаются: после правки «через центры» впервые даёт другое отражение, чем раньше. Если раньше камера сама подгонялась (не было явного выключения), теперь по умолчанию не подгоняется; включённую вручную подгонку браузер помнит.
