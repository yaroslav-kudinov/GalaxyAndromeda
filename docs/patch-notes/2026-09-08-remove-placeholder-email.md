# Убран временный адрес поддержки с главной и из правовых текстов

Дата: 2026-09-08
Ветка: agent/remove-placeholder-email

## Суть

На главной странице и в правовых документах больше не показывается временный адрес электронной почты-заглушка. Блок «Поддержка» с этим адресом убран, чтобы игроки не писали на нерабочий контакт.

## Правила

Правила игры не менялись.

## Код

- Клиент: `packages/client/pages/index.vue` — убрана строка поддержки в подвале главной.
- Публичные правовые страницы: `packages/client/public/legal/terms-of-use.html`, `privacy-policy.html` — убрана строка контакта.
- Документы: `docs/legal/terms-of-use.md`, `docs/legal/privacy-policy.md` — секции контактов с заглушкой удалены.
- `LICENSE`, `NOTICE` — убраны упоминания того же адреса-заглушки.

## API / контракт

Контракт для программ не менялся.

## UI

В подвале главной страницы больше нет строки «Поддержка» с адресом электронной почты. На страницах условий использования и политики конфиденциальности контактный адрес-заглушка тоже убран. Ссылки на условия и конфиденциальность остаются.

## Тесты

Вручную: открыть главную, подвал без блока поддержки; открыть условия использования и политику конфиденциальности — без адреса-заглушки.

## Миграции

Миграция сохранений не нужна.
