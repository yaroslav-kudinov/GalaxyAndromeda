# Крейсер в прямом бою бросает 2d4

Дата: 2026-08-26
Ветка: agent/debug-combat-markers-ui

## Суть

Крейсер на клетке боя теперь слабее бьёт кубиками: вместо двух шестигранников — два четырёхгранника. Два эсминца против одного крейсера (без поддержки с соседних клеток) чаще выигрывают раунд. Поддержка крейсера с дистанции не менялась.

## Правила

- Было: крейсер на клетке боя — 2d6; поддержка с дистанции — 1d4.
- Стало: крейсер на клетке боя — **2d4**; поддержка с дистанции — по-прежнему 1d4.
- Эсминец: 1d6, цена уничтожения 4 — без изменений.
- Линкор и остальные типы — без изменений по боевым кубикам на клетке.
- Оценка: два эсминца против одного крейсера без поддержки выигрывают раунд примерно в 69% бросков (~77%, если ничьи не считать и перебрасывать). Это чуть сильнее «около 60%»; если нужно ближе к шестидесяти — можно обсудить 2d5.

## Код

`packages/rules/data/ships.yaml` — `combatDieFaces: 4` у крейсера; `packages/rules/src/combat.ts` — `SHIP_COMBAT_DIE_FACES` и бросок через `rollDice`; справка игрока и `docs/rulebook.md`.

## API / контракт

Контракт снимка партии не менялся. Изменилась интерпретация боевых кубиков крейсера при броске раунда.

## UI

В справке по правилам у крейсера в колонке боя указано «2d4» вместо «2d6».

## Тесты

`rulebook-compliance` и `combat.test` — грани крейсера в бою; гонять `pnpm --filter @galaxy/rules test`.

## Миграции

Миграция сохранений не нужна.
