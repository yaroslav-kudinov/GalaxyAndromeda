# Патчноуты

Каждое содержательное изменение проекта сопровождается файлом в этой папке. Игроки читают те же тексты в клиенте на странице `/patch-notes`.

## Для игрока

Заметки написаны человеческим русским языком: что изменилось в партии, без сокращений и без английских ярлыков. Термины те же, что в правилах: нейтральная клетка, контролируемая клетка, центр власти, фишки кредитов и производства, маркер действия, маркер производства, регион, сдача, колода событий.

## Для агента

Как писать, когда писать и полный глоссарий — в правиле [`.cursor/rules/patch-notes.mdc`](../../.cursor/rules/patch-notes.mdc). Не копируй глоссарий сюда: следуй правилу.

Краткая памятка:

- Секции «Суть», «Правила», «UI» — только для игрока, полными предложениями.
- Имена файлов, коды карт и поля программ — только в «Код» и «API / контракт».
- Историческую заметку не переписывай под нынешние правила: она про тот день.
- Не плоди второй файл за тот же заход: дополни существующий.

Лента `docs/changelog.md` остаётся короткой; патчноут объясняет смысл изменения.
