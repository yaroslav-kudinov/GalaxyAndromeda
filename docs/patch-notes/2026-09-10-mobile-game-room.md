# На телефоне карту можно двигать пальцем, а шапка партии стала компактнее

Дата: 2026-09-10
Ветка: main

## Суть

В игровой комнате на узком экране карту можно сдвигать перетаскиванием пальцем или левой кнопкой мыши, а масштаб меняется щипком двумя пальцами. Вертикальная тёмная полоса слева оказалась панелью масштаба поверх карты — на телефоне она скрыта полностью. Короткое касание по-прежнему выбирает клетку. Шапка компактнее: действие фазы внизу, меню «Ещё», имя в шапке, кнопка «Игра» без колонки-подложки.

## Правила

Правила игры не менялись.

## Код

- Карта: `packages/client/components/HexBoard.vue` — pan с порогом, ПКМ/СКМ, надёжный pinch-zoom (слушатели на окне), на узком экране в режиме партии скрыт `.zoom-bar--overlay`.
- Комната: `packages/client/pages/game/[roomId].vue` — убран ошибочный `top` у zoom-bar (из‑за него полоса тянулась на всю высоту); узкий режим шапки и панели.
- Чат: `packages/client/components/RoomChatPanel.vue` — крупнее кнопки на узком экране.

## API / контракт

Контракт для программ не менялся.

## UI

- На телефоне панель масштаба слева больше не показывается: приближение и отдаление — щипком двумя пальцами. На компьютере остаются колесо мыши и кнопки «плюс» / «минус» в углу карты.
- Карту можно двигать перетаскиванием; короткое касание выбирает клетку.
- Шапка на узком экране компактная; кнопка фазы внизу; панель «Игра» и чат не оставляют пустую колонку поверх карты.

## Тесты

- `pnpm --filter @galaxy/client test` и проверка типов клиента.
- Вручную при ширине около 390 пикселей: нет левой полосы масштаба, щипок меняет масштаб, перетаскивание двигает карту, касание выбирает клетку.
