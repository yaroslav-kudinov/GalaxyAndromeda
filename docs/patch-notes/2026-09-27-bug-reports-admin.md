# Баг-репорты в админ-панели

Дата: 2026-09-27
Ветка: claude/bug-reports-admin

## Суть

Баг-репорты, которые игроки отправляют кнопкой «Баг», теперь можно прочитать в админ-панели.
Раньше сервер только складывал их на диск, и достать их можно было лишь из файлов хостинга.

## Скачать репорты к себе

`pnpm bug-reports:pull` скачивает репорты в папку `bug-reports-inbox/` в корне репозитория (в git не
попадает): `index.md` — общий список, новые сверху; в папке каждого репорта — `report.md` с полным
текстом и `screenshot.png`. Уже скачанные повторно не качаются. `--delete` после скачивания
удаляет репорты с сервера, в том числе скачанные раньше.

Токен администратора команда берёт из `GALAXY_ADMIN_TOKEN` в `.env.local` в корне основной папки
репозитория и нигде не печатает. Адрес сервера — `GALAXY_SERVER_URL`, по умолчанию хостинг.
Эту же папку удобно отдавать агенту: он читает и тексты, и скриншоты.

## Правила

Правила игры не менялись.

## Код

Для разработчиков: `listBugReports`, `readBugReportScreenshot`, `deleteBugReport` и
`registerBugReportAdminRoutes` в `packages/server/src/bug-reports.ts`; маршруты подключены в
админской части API (`registerAdminRoutes`) и проверяют токен администратора. Идентификатор
репорта принимается только в виде UUID — путь к чужим файлам через него не передать.
Вкладка — в `packages/client/pages/admin/index.vue`.

## API / контракт

Новые запросы, только для администратора (`Authorization: Bearer <GALAXY_ADMIN_TOKEN>`):
`GET /api/admin/bug-reports`, `GET /api/admin/bug-reports/:id/screenshot`,
`DELETE /api/admin/bug-reports/:id`. Описаны в `docs/agent-protocol.md`. Отправка репорта не
менялась.

## UI

- В админ-панели появилась вкладка «Баг-репорты». Репорты идут новыми сверху: дата, игрок,
  комната, текст, браузер и срок хранения.
- Скриншот загружается кнопкой «Показать скриншот» и открывается во вкладке по ссылке.
- Разобранный репорт можно удалить; удаление спрашивает подтверждение.

## Тесты

- Сервер: список новых сверху, скриншот, удаление, отказ на путь вместо идентификатора.
- Браузер: вход в админку по токену, список, загрузка скриншота; запрос без токена — 401.
- Команда скачивания против локального сервера: два репорта со скриншотом, повторный прогон ничего
  не качает, `--delete` удаляет и ранее скачанные, неверный токен — понятная ошибка.

## Миграции

Не нужны. Репорты лежат там же — в `bug-reports` каталога данных (`GALAXY_DATA_DIR`, на Amvera —
`/data`), хранятся 60 дней.
