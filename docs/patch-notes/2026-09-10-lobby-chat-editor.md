# Карта «Пятиконечный путь» получила стартовые флоты; лобби, чат комнаты и редактор карт

Дата: 2026-09-10
Ветка: main

## Суть

На официальной карте «Пятиконечный путь» у каждого дома снова есть стартовые корабли — как на «Шестиконечном пути»: четыре эсминца и два крейсера. Экран подготовки комнаты упрощён: главное действие хоста или ожидание игрока на виду, остальное свёрнуто. В комнате (подготовка и партия) появился общий чат и личные сообщения. В редакторе карт — подсказки клавиш внизу, мультивыделение клеток с копированием и вставкой, числовой ввод для фишек ресурсов.

## Правила

Правила игры не менялись. Стартовый расклад «Пятиконечного пути» теперь совпадает по составу флота с «Шестиконечным путём»: на каждом центре власти дома — два эсминца, на клетках с фишкой кредитов и фишкой производства — по одному крейсеру.

## Код

- Карта: исходник `maps/bundled/five-point-path.source.galaxy.json`, нормализованные копии в `maps/bundled/` и `packages/client/public/maps/` через `harness/scripts/import-bundled-maps.ts`.
- Лобби комнаты: компонент `packages/client/components/RoomLobbyPanel.vue`, стили адаптивной шапки комнаты.
- Чат: сервер `packages/server/src/room-chat.ts`, маршруты в `room.ts`; клиент `RoomChatPanel.vue` и composable опроса.
- Редактор: `useMapEditorHotkeys.ts`, `pages/editor/index.vue` — мультивыделение, нижняя панель подсказок, числовой ввод фишек.
- ADR: `docs/decisions/014-room-chat.md`.

## API / контракт

- `GET /api/rooms/:id/chat?playerId=&after=` — сообщения, видимые игроку (общий канал и личные с его участием).
- `POST /api/rooms/:id/chat` — тело `{ playerId, text, toPlayerId? }`; без `toPlayerId` — общий чат. Лимиты длины и частоты на сервере.

## UI

- В списке официальных карт у «Пятиконечного пути» на карте видны стартовые эсминцы и крейсеры.
- Комната подготовки: крупная кнопка «Начать игру» у создателя; у остальных — ожидание; ссылка-приглашение, закрытие комнаты и музыка — во вторичном блоке.
- Сворачиваемая панель чата в комнате (подготовка и партия), не на главной странице.
- Редактор: подсказки клавиш внизу экрана; выделение нескольких клеток с копированием, вырезанием, вставкой и удалением; числовое поле рядом с ползунком фишек.

## Тесты

- Импорт bundled-карт: «Пятиконечный путь», пять игроков, тридцать стартовых кораблей (по шесть на дом).
- `pnpm test` / `pnpm typecheck` по затронутым пакетам; ручная проверка лобби, чата и редактора.

## Миграции

Существующий файл базы не сбрасывается. При старте сервера сид каталога заново записывает bundled-карты из файлов репозитория — обновлённый «Пятиконечный путь» со стартовыми флотами подхватится после перезапуска сервера. Историю чата сервер не хранит на диске.
