# В каталог добавлена карта «Пятиконечный путь»

Дата: 2026-09-06
Ветка: agent/public-release-prep

## Суть

В официальный набор карт для выбора в лобби добавлена карта «Пятиконечный путь» на пятерых. После обновления сервера она появляется в каталоге даже если база уже была заполнена раньше.

## Правила

Правила игры не менялись.

## Код

- Источник и нормализованная карта: `maps/bundled/five-point-path*`, копия для клиента в `packages/client/public/maps/`.
- Импорт: `harness/scripts/import-bundled-maps.ts`.
- Сид базы: `seedBundledMaps` в `packages/server/src/db/index.ts` добавляет только отсутствующие bundled-карты, не затирает уже сохранённые.

## API / контракт

`GET /api/catalog/maps` отдаёт новую карту с идентификатором `five-point-path` после сида.

## UI

В списке официальных карт лобби появляется «Пятиконечный путь» (пять игроков).

## Тесты

Импорт прогнан: пять игроков, 229 клеток. После выкладки на хостинг — создать комнату из этой карты.

## Миграции

Существующий файл базы не сбрасывается. При старте сервера недостающая bundled-карта вставляется в каталог.
