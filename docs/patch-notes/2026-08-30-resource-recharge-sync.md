# Синхронизация счётчика перезарядки ресурсов

Дата: 2026-08-30
Ветка: agent/debug-combat-markers-ui

## Суть

В мультиплеере у разных игроков показывались разные значения «до перезарядки». Дополнительно интервал перебрасывался в лобби при каждом опросе сервера: клиент получал пустое поле и заново бросал кубик.

## Правила

Случайный интервал 1–3 хода задаётся **один раз** при старте партии и **один раз** после каждой автоперезарядки в конце полного хода. В комнате подготовки счётчик не показывается и не бросается.

## Код

- `packages/server/src/room.ts` — поле `resourceRechargeTurnsRemaining` в observation только при `status === 'playing'`.
- `packages/rules/src/resource-recharge.ts` — `migrateResourceRechargeSchedule` без броска, `rollNewResourceRechargeSchedule` для явного броска.
- `packages/rules/src/match-start.ts`, `save-file.ts` — убраны скрытые броски при нормализации.

## API / контракт

В observation (`mechanics`) поле `resourceRechargeTurnsRemaining` приходит только после старта партии.

## UI

До нажатия «Начать игру» баннер перезарядки не показывается. После старта и при перезарядке все игроки видят одно значение.
