# В игровой комнате за картой виден космос, клетки слегка просвечивают

Дата: 2026-08-25
Ветка: agent/debug-combat-markers-ui

## Суть

Поле партии больше не лежит на глухом тёмном прямоугольнике. За картой открывается снимок глубокого космоса: звёзды и далёкая туманность. Клетки остаются читаемыми, но заливка чуть прозрачная, чтобы сквозь гексы угадывалось небо. Корабли, маркеры, фишки ресурсов и границы территорий не прячутся за эффектом.

Редактор карт не трогали: там клетки по-прежнему сплошные, без космического фона, чтобы удобно править гексы.

## Правила

Правила игры не менялись.

## Код

Для разработчиков: картинка `packages/client/public/images/space-bg.jpg`. Фон на `.game-viewport` в `packages/client/pages/game/[roomId].vue` (`background-size: cover`, лёгкий затемняющий градиент сверху). Полупрозрачная заливка — свойство `translucentCells` у `HexBoard.vue` / `GameBoard.vue` (непрозрачность заливки `0.68`); редактор свойство не передаёт, заливка остаётся сплошной.

## API / контракт

Контракт для программ не менялся.

## UI

В комнате партии (и на экране подготовки той же комнаты, пока за карточкой входа видна карта) весь игровой стол закрыт космической картиной. Шапка и боковая панель как прежде с собственной подложкой, текст на них читается. Нейтральные и контролируемые клетки по-прежнему различаются по цветной кайме территории; через середину гекса слегка виден космос. Превью карты на главной странице и редактор без этих изменений.

## Тесты

Автоматических проверок нет. Вручную: открыть комнату — за картой космос, клетки не «пустые», корабли и маркеры читаются; открыть редактор — сплошные клетки, без космической картины.

## Миграции

Миграция сохранений не нужна.
