# Убрана карта «Всё для фронта» из колоды событий

Дата: 2026-08-31
Ветка: agent/debug-combat-markers-ui

## Суть

Карта «Всё для фронта» ограничивала трату фишек производства за ход. Такие ограничения по событиям больше не нужны: в колоде не остаётся карт, которые меняют правила расхода фишек производства.

## Правила

Убрана карта «Всё для фронта» и её эффект «не более трёх фишек производства на игрока за ход». При постройке кораблей лимит по фишкам производства от событий больше не проверяется.

В колоде осталось 9 типов карт (14 карт с учётом копий). Старые сохранения и колоды с кодом `all-for-front` при загрузке заменяют эту карту на «Среди звёзд лишь пустота».

## Код

Пакет `@galaxy/rules`: `events.ts` (удалены карта, модификатор и учёт трат), `production.ts` (снята проверка лимита), `events.test.ts`.

## API / контракт

Поле `productionTokensSpentThisTurn` в сейве остаётся для совместимости, но больше не обновляется. Контракт observation для клиента не менялся.

## UI

В справке игрока и в rulebook убрана строка про «Всё для фронта»; число типов карт — 9.

## Тесты

Обновлены тесты колоды и миграции `migrateLegacyEventId('all-for-front')`.

## Миграции

Старые сейвы с `all-for-front` в колоде или на столе мигрируют в «Среди звёзд лишь пустота». Отдельная миграция сохранений не требуется.
