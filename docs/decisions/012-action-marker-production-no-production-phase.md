# ADR 012: Производство через маркер действия, без фазы производства

Дата: 2026-08-29

## Контекст

Упрощение цикла хода: постройка кораблей в фазе «Действия» по маркеру действия; маркеры производства и отдельная фаза снимаются. Перезарядка фишек — автоматически раз в N ходов.

## Решение

- `Phase`: значение `production` остаётся в типе для миграции старых сейвов; в `PHASE_ORDER` только `events`, `planning`, `actions`.
- Постройка: `execute-production` в фазе «Действия», `markerId` — маркер действия; корабли только на клетке маркера.
- Клейм клеток: при переходе «Действия» → «События» (конец игрового хода).
- `resourceRechargeTurnsRemaining`: 1 | 2 | 3 на снимке партии; случайный новый интервал после каждой перезарядки; автопереворот face-down фишек в конце хода.
- Лимит маркеров действия: **3 + число центров власти** (при одном центре — 4).
- Бой: эсминец 1d4, крейсер 2d6; эсминец захватывает нейтраль только жертвой по маркеру действия.

## Последствия

- `productionMarkers` в сейвах очищаются при нормализации.
- Клиент и MCP: убрать UI/действия PM и фазы производства.
