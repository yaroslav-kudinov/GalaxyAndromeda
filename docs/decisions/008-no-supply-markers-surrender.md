# ADR 008: Без снабжения, оплата из региона, пулы маркеров, клейм производства, сдача

## Status

Accepted

## Context

Корабли снабжения были обязательны для экономики и захвата. Цепочки снабжения позволяли платить из всей связной империи. Лимиты маркеров не давали покупки ёмкости. Захват с хода делал эсминец универсальным колонизатором. Нужна сдача по оригиналу: контроль снимается, боевой флот остаётся.

## Decision

### Типы (`types.ts`)

- Из `ShipType` убран `supply`. Сейвы и карты: единицы `supply` удаляются при нормализации.
- Бой: любой вражеский корабль на клетке. `declareControl` удалён.

### Оплата

- Постройка и перезарядка — только гексы **региона маркера**.
- `spatialSummary.supplyChains` остаётся как связный контроль для агентов, оплату не кормит.

### Пулы маркеров (`GameSnapshot`)

```
actionMarkerLimitByPlayer?: Record<string, number>       // старт 3, макс 8
productionMarkerLimitByPlayer?: Record<string, number>   // старт 1, макс 3
```

Покупка в производстве:

- маркер действия: 4-й слот **6+6**, каждый следующий **+2/+2** (до 14+14); фишки региона, переворот; можно вместе с кораблями;
- маркер производства: 2-й **8+6**, 3-й **12+9**; фишки снимаются с карты с любых своих клеток лицом вверх; отдельное действие, не смешивается с постройкой.

Событие `production-accident`: нельзя покупать доп. маркеры.

### Клейм

Мирный вход контроль не берёт. При **входе в фазу производства** (один раз на всех): клетка с вашими кораблями без вражеских:

- нейтраль — клейм только если есть корабль **не** эсминец;
- чужой контроль без флота — клейм даже одними эсминцами (рейд), чужой маркер производства снимается.

Бой: переход контроля без изменений.

### Сдача

Действие `surrender` в любой момент. Игрок `eliminated`, контроль снят, маркеры сняты, корабли остаются. Поддержка ему нельзя, против него можно.

## Consequences

- Клиент: клейм без UI-клика; покупка AM в пакете постройки; отдельная кнопка PM; кнопка сдачи.
- Протокол: `surrender`, `buy-action-marker` (в batch), `buy-production-marker`.
- Карты: стартовое снабжение → эсминцы.
