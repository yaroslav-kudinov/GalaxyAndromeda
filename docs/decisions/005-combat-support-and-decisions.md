# ADR 005: Поддержка третьей стороны и решения о продолжении боя

## Status

Accepted

## Decision

`CombatOptions.supportSides` хранит выбор игрока вне основных сторон: все его корабли с `supportDice` в допустимом `fireRange` добавляются атакующему или защитнику. Такой игрок не участвует в ready/countdown и не объявляет priority skip.

`PendingCombat.continueDecisions` хранит порядок решений после раунда: сначала attacker, затем defender. Следующий раунд начинается только после двух положительных решений; любой текущий решающий участник может отступить в соседнюю клетку без вражеских кораблей, если событие «Стоять насмерть!» не запрещает это. Для боя, начатого движением, `PendingCombat.continuation` сохраняет исходную клетку и атакующие корабли до окончательного разрешения: это исключает ошибочное перемещение флотов обеих сторон на один гекс между раундами.

## Consequences

- `update-combat-prep` принимает необязательный `supportSide`.
- Клиенты получают кандидатов поддержки через `CombatPreview.supportCandidates`.
