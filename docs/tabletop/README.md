```bash
pnpm tabletop:print
```

## Печать

- Формат **A4**, цвет, двусторонняя печать **не обязательна** (рубашки карт событий — отдельные листы).
- Карты поля: плотная бумага или наклейка на картон.
- Жетоны и карты событий: 200–300 г/м², разрезать по пунктиру.
- Кубики в комплект не входят: нужны **d6** и **d4**.

## Карты в комплекте

- **Duel (2 игрока)** — `maps/duel-2p.json`: 23 гекса, 3 центра власти, стартовые снабжение + эсминец.
- **TTS Reference (3 игрока)** — `maps/tts-reference.json`: стартовые территории без кораблей в файле карты; за столом положите снабжение + эсминец на домашнюю клетку (см. правила).

Карта `maps/default.json` — отладочная заглушка, в PDF её нет.
