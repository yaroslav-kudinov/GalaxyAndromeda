## Победа и поражение

**Победа** (любое из условий):

1. **4 региона по 7+ клеток** — связные контролируемые территории игрока, каждая размером не меньше 7.
2. **Большинство центров власти** — контроль строго больше половины всех центров власти на карте.
3. **Последний на карте** — единственный невыбывший игрок с кораблями или контролем.

**Поражение:** игрок теряет **все** клетки с центром власти → статус `eliminated`, исключается из очереди хода.

Проверка выполняется после смены контроля, боя и завершения фазы производства.

## Карта и контроль

- Гексовая сетка; соседство только по граням.
- **Регион** — связная компонента контролируемых клеток одного игрока.
- **Ресурсы:** кредиты (жёлтые фишки 1–9), производство (оранжевые 1–9).
- **Центр власти** — отдельный маркер на клетке (не путать с фишкой кредитов).

## Цепочки снабжения

**Цепочка снабжения** — связная компонента соседних по грани **контролируемых** клеток игрока. Несколько регионов в одной компоненте образуют одну цепочку.

При **производстве** фишки оплаты можно брать с **любой** клетки той же цепочки, что и регион маркера (не только из региона маркера). Корабли размещаются только в регионе маркера.

## Корабли

См. `packages/rules/data/ships.yaml`.

Типы: эсминец, крейсер, линкор, щитоносец, гиперпространственное орудие, снабжение.

**Лимиты флота (на игрока):** эсминец 16, снабжение 10, крейсер 12, линкор 6, щитоносец 4, гиперпространственное орудие 2.

**Числовые показатели боя:** у эсминца цена уничтожения **4**. Корабли в клетке боя бросают свои боевые кубики как d6. Кубики поддержки с дистанции: крейсер — 1d4, линкор — 2d4, гиперпространственное орудие — 3d4; число кубиков поддержки и дальность стрельбы не меняются.

**Движение:** дальность хода — длина **пути по существующим гексам** карты (поиск в ширину по соседним граням). Через «дыры» (где гекса нет) лететь нельзя. Поддержка и обстрел по дальности стрельбы пока считаются осевым расстоянием (может уточняться отдельно).

## Бой и обстрел

**Раунд:** пропуск приоритета (по **типу** корабля, один пропуск на тип — все экземпляры на гексе) → кубики (+ поддержка) → победитель раунда → щиты → **ручной выбор уничтожения** победителем (или автоматическое полное уничтожение, если урон покрывает весь флот проигравшего).

**Пропуск приоритета:** объявляется до броска, без оплаты фишками, **только на текущий раунд**. Игрок пропускает **типы кораблей противника** строго по порядку приоритета уничтожения среди типов, присутствующих в бою (эсминцы → гиперпространственное орудие → щитоносец → крейсер → линкор → снабжение; отсутствующий тип не учитывается). Нельзя пропустить крейсер, пока не пропущен эсминец (и т.д. по цепочке). Пропуск **последнего** присутствующего типа бессмысленен и запрещён — после пропуска всех предыдущих уже можно уничтожать любой оставшийся корабль. Если игрок выиграет раунд, каждый пропущенный тип у проигравшего дороже на **+1** к цене уничтожения (линкор 9→10) и его можно обойти при выборе уничтожения (открывается следующий уровень).

**Поддержка третьей стороны:** игрок, не являющийся атакующим или защитником, но имеющий корабли с кубиками поддержки в дальности стрельбы от клетки боя, может в подготовке направить все такие корабли атакующему или защитнику. Поддерживающий не объявляет пропуск приоритета и не подтверждает готовность; без доступных кораблей он видит только уведомление о предстоящем бое.

**Кубики поддержки:** крейсер / линкор / гиперпространственное орудие бросают с дистанции соответственно 1d4 / 2d4 / 3d4. Их боевые кубики на гексе боя остаются d6; поддержка не меняет число кубиков.

**Уничтожение:** победитель раунда выбирает корабли проигравшего в рамках бюджета урона; доступны только цели с соблюдением порядка приоритета (кроме события «Хаос битвы»). Корабли первого доступного уровня подсвечиваются как «сразу уничтожаемые».

**Очки уничтожения:** после бросков сравниваются суммы кубиков сторон; победитель — сторона с большей суммой. Проигравший получает **разницу** между суммами (|атакующий − защитник|), а не полную сумму победителя. Пример: атакующий 15, защитник 7 → **8** очков уничтожения; щит на клетке поглощает 4 → остаётся **4** на уничтожение. Неиспользованные очки сгорают в конце раунда.

**Выбор уничтожения:** победитель раунда вручную выбирает корабли проигравшего в рамках бюджета и приоритета; интерфейс не даёт выбрать корабль, если его цена уже не помещается в оставшийся бюджет. Если бюджет меньше цены уничтожения каждого доступного корабля (включая надбавку пропуска приоритета), раунд считается ничьёй без уничтожения и сразу переходит к решению о продолжении (отступление ещё недоступно, пока в бою никто не уничтожен).

**Многораундовый бой:** после раунда, если на гексе остаются вражеские корабли, бой может идти дальше. Пока в текущем бою не уничтожен ни один корабль, отступление недоступно — раунды идут автоматически, пока рандом не даст уничтожение или конец боя (игроки наблюдают). После первого уничтожения сначала атакующий, затем защитник выбирают **продолжить** или **отступить**; следующий раунд — после двух «продолжить». Отступление также запрещено событием «Стоять насмерть!». При отступлении игрок выбирает любую соседнюю клетку без вражеских кораблей. **Маркер действия** привязан к игроку: если на клетке не осталось кораблей владельца маркера (уничтожение или уход), маркер снимается. При победе атакующего в бою движением его корабли **входят** на клетку боя. На одном гексе могут быть 3+ игрока — защитники определяются по всем чужим кораблям на клетке.

**Обстрел:** крейсер, линкор, гиперпространственное орудие — атака по гексу в дальности стрельбы без входа. Гиперпространственное орудие: дальность **2–3** (не соседняя). За один маркер можно обстрелять **несколько** клеток (очередь подготовки). Подготовка — только атакующий; защитник **не бросает кубики**. Очки уничтожения = **сумма броска обстрела**; щиты работают; клетка **не захватывается**. Движение в клетку с врагами: по-прежнему **одна** клетка боя на маркер.

## Производство

- Размер региона задаёт **минимум** клеток для класса корабля (`ships.yaml`).
- Оплата фишками лицом вверх из цепочки снабжения; потраченные переворачиваются рубашкой вверх.
- Регион с доступным производством и перевёрнутыми ресурсами в его цепочке снабжения: **перезарядка** или **постройка** — не оба за один ход маркера. Перезарядка переворачивает лицом вверх все перевёрнутые фишки ресурсов цепочки: кредиты и производство.
- Пакетная постройка: несколько кораблей, размещение на любых гексах региона.

**Маркеры:** действие — до 6, 1 на гекс. Маркер производства ставится в один подходящий регион
(не меньше 3 клеток, полоса эсминца), по одному на регион. Первый маркер базовый; второй доступен
при 3 отдельных контролируемых регионах по не меньше 4 клеток, третий — при 5 таких регионах.

## Порядок хода и фазы

Один игровой ход всегда проходит четыре фазы по порядку: **События → Планирование → Действия → Производство**. После производства начинается следующий ход с новой картой события.

### 1. События

- Вытягивается одна карта события на всех игроков из **колоды**.
- Колода заранее перемешана; карта снимается сверху. Когда карты закончились — колода собирается заново (полный комплект с кратностью карт) и снова перемешивается.
- Жёсткие эффекты встречаются реже (в колоде меньше копий), мягкие и полезные — чаще.
- Активный игрок применяет карту: немедленные эффекты срабатывают сразу; модификаторы действуют до конца этого хода.
- После применения начинается «Планирование».

### 2. Планирование

- Игроки по очереди расставляют (или снимают) маркеры на карте. Корабли ещё не двигаются и не строятся.
- Сначала — маркеры действия: клетка с вашим кораблём; не больше 6 на игрока, не больше одного на клетку.
- Затем — маркеры производства: подходящий регион; один маркер на регион; число маркеров зависит от числа крупных регионов.
- На одной клетке могут одновременно стоять маркер действия и маркер производства.
- Доступное действие: поставить или снять маркер. Если действия нет — игрок автоматически пропускается.
- Когда все закончили планирование, начинается «Действия».

### 3. Действия

- Порядок хода: **меньше контролируемых регионов — раньше** (при равенстве — исходный порядок слотов).
- Фаза идёт, пока на карте есть маркеры действия. За ход игрок исполняет один свой маркер или снимает его без действия (снятие — только до исполнения, с подтверждением).
- Исполнение: выбор кораблей → перемещение и/или обстрел. Вход на клетку с врагами начинает бой.
- Доступное действие: использовать или снять свой маркер действия. Если маркеров нет — автоматический пропуск.
- Когда все маркеры действия сняты/исполнены, начинается «Производство».

### 4. Производство

- Порядок хода снова: **меньше регионов — раньше**.
- Фаза идёт, пока на карте есть маркеры производства. За ход игрок исполняет один свой маркер.
- Исполнение: либо постройка в регионе маркера (оплата фишками лицом вверх из цепочки снабжения), либо перезарядка всех перевёрнутых фишек цепочки — не оба действия за один маркер.
- Неразрешённый маркер производства нельзя «пропустить»: нужно построить, перезарядить или снять маркер.
- Доступное действие: использовать или снять свой маркер производства. Если маркеров нет — автоматический пропуск.
- Когда все маркеры производства сняты/исполнены, ход заканчивается; дальше снова «События» следующего хода.

## Карты событий

| ID | Название | Эффект |
|----|----------|--------|
| `magnetic-storm` | Магнитная буря | Дальность хода −1 (мин. 1) |
| `empty-void` | Среди звёзд лишь пустота | Без эффекта |
| `stand-to-death` | «Стоять насмерть!» | Нельзя отступать из боя |
| `saboteurs-activation` | Диверсанты | Все фишки в контролируемых регионах — рубашкой вверх |
| `production-accident` | Авария на производстве | Нельзя строить снабжение |
| `ammo-detonation` | Детонация склада | Нельзя строить эсминец / крейсер / линкор |
| `peoples-donation` | Народное пожертвование | Все фишки лицом вверх |
| `mandatory-overtime` | Сверхурочные | Любое число фишек производства в одном регионе (не больше клеток региона) |
| `hyper-gap` | Просвет в гиперпространстве | Ход +1; дальность стрельбы гиперпространственного орудия = 4 |
| `all-for-front` | «Всё для фронта» | +3 фишки производства на игрока (на пустые контролируемые клетки) |
| `shadow-economy` | Теневая экономика | Номинал фишки +2 при оплате |
| `hold-formation` | «Держать строй» | Цена уничтожения +2 |
| `combat-chaos` | Хаос битвы | Приоритет уничтожения отключён |
| `local-self-defense` | Местная самооборона | Запрет **входа** на клетки с фишками / центром власти |

Типов карт — 14. В полной колоде больше 14 карт за счёт копий: жёсткие эффекты — по 1 копии, средние — по 2, мягкие/полезные — по 2–3. После исчерпания колода перетасовывается заново.
