# Деплой на Railway

Один контейнер отдаёт **интерфейс** (Nuxt) и **API** (`/api/...`) на одном порту. Railway подставляет переменную `PORT` автоматически.

## Требования

- Аккаунт [Railway](https://railway.app)
- Репозиторий на GitHub / GitLab / Bitbucket
- В репозитории есть `Dockerfile` и `railway.toml` в корне

## Шаги

1. Залейте проект в git-репозиторий (если ещё не залит).
2. Railway → **New Project** → **Deploy from GitHub repo** → выберите репозиторий.
3. Railway соберёт образ по `Dockerfile` (5–10 минут при первом деплое).
4. В настройках сервиса откройте **Networking** → **Generate Domain** — получите URL вида `https://ваш-проект.up.railway.app`.
5. Откройте URL в браузере: главная, лобби и создание комнаты должны работать как локально.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `PORT` | Railway задаёт сам | Порт HTTP |
| `HOST` | `0.0.0.0` | Слушать все интерфейсы |
| `NODE_ENV` | `production` в образе | Режим production |
| `CLIENT_STATIC_DIR` | `/app/packages/client/.output/public` | Каталог статики Nuxt |
| `LOG_LEVEL` | выкл. | Уровень логов Fastify (`info`, `warn`, …) |
| `BUG_REPORTS_DIR` | `.bug-reports` в образе | Каталог баг-репортов (эфемерный диск) |

Дополнительно настраивать обычно не нужно.

## Проверка здоровья

- `GET /api/health` — основная проба (настроена в `railway.toml`)
- `GET /health` — дублирующая короткая проба

## Локальная проверка образа

```bash
pnpm run build:deploy
docker build -t galaxy-andromeda .
docker run --rm -p 8080:3001 -e PORT=3001 galaxy-andromeda
```

Откройте `http://localhost:8080`.

## Ограничения production

- **Комнаты в памяти:** перезапуск контейнера обнуляет активные партии. Для друзей это обычно приемлемо; для публичного сервиса позже понадобится volume или БД.
- **Диск эфемерный:** баг-репорты и временные файлы не сохраняются между деплоями.
- **Один инстанс:** для нескольких реплик нужна общая память комнат (сейчас не реализовано).

## Обновление

Пуш в ветку, привязанную к Railway, запускает новый деплой автоматически.

## Сборка без Docker (справка)

```bash
pnpm install
pnpm run build:deploy
PORT=3001 node packages/server/dist/index.js
```

Клиент должен быть собран через `nuxt generate` (скрипт `build:deploy` делает это сам).
